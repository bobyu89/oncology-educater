# 健保藥品給付規定原文

各章「9. 健保給付與事前審查」依《全民健康保險藥品給付規定》原文整理，逐條標註條號。

## 目前版本

| 檔案 | 內容 |
|------|------|
| `nhi-drug-rules-1151022.docx` | 全民健康保險藥品給付規定全文（115 年 10 月 22 日版，使用者提供） |
| `section9-1151022.md` | 由上述 docx 轉出的第 9 節「抗癌瘤藥物」，方便在 GitHub 上搜尋；有疑義時以 docx 為準 |

共用章節引用的其他條文也在全文檔中：4.1.2 G-CSF、5.5.3.2.1 zoledronic acid、5.5.4 denosumab、5.5.6 rasburicase、7.2.1–7.2.3 止吐藥、10.7.3 B 型肝炎用藥、通則十二（生物標記檢測報告）。

## 改版時

1. 從健保署網站下載新版藥品給付規定全文。
2. 放進這個資料夾（檔名保留公告日期），或直接在 Claude 對話中上傳。
3. 比對差異後更新各章第 9 段的條號與條件，並更新各章開頭的「健保給付」版本欄位。

健保署網站會擋自動抓取，所以需要人工下載。
