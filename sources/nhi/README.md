## 放什麼

- 健保署公告的最新版**第 9 節「抗癌瘤藥物」**（PDF 或 ODT）。
- 檔名請保留公告日期，例如 `第9節抗癌瘤藥物_1151001.pdf`，日後改版時才能對照。
