# 編寫規範（Style Guide）

這份規範是每一章的共同骨架。新增癌別時照著它寫，手冊才會「翻到哪一章都長得一樣」，查房時才找得快。

---

## 1. 語言與術語

- 正文用**繁體中文**；醫學術語、藥名、試驗名、分期符號保留**英文**。
- 術語第一次出現時寫成：中文（English, 縮寫），例如：非小細胞肺癌（non-small cell lung cancer, NSCLC）。之後直接用縮寫。
- 藥名一律用**學名**（generic name，小寫），必要時括號附商品名：osimertinib（Tagrisso®）。
- 劑量單位：mg/m²、mg/kg、AUC、mg QD／BID、q3w（每 3 週）、D1,8（第 1、8 天）。

## 2. 章節固定模板

每個癌別一個檔案（`handbook/NN-<cancer>.md`），章節編號固定，方便跨癌別對照：

| # | 章節 | 內容重點 |
|---|------|---------|
| 0 | 速查卡（Quick Card） | 一頁看完：分型、必驗 biomarker、各期治療主軸、必背數字 |
| 1 | 流行病學與危險因子 | 台灣癌登／死因統計（註明資料年）、危險因子、篩檢政策 |
| 2 | 病理與分子標記 | 組織分型、IHC、必驗 biomarker 與檢測方法 |
| 3 | 診斷與分期 | Work-up 流程、AJCC 分期表（註明版次）、預後 |
| 4 | 治療策略（依分期） | 依期別寫 algorithm，每個建議附指引與關鍵試驗 |
| 5 | 常用處方（Regimen） | 劑量、週期、premedication、給藥前檢核 |
| 6 | 副作用評估與處置 | 依藥物類別，CTCAE 分級 → 處置 → 何時停藥／減量 |
| 7 | 專師實務 | Order set 範例、SOAP／progress note 範例、追蹤時程 |
| 8 | 腫瘤急症（本癌別相關） | 本癌別特有的急症；通用急症連到共用章節 |
| 9 | 健保給付與事前審查 | 依《藥品給付規定》第 9 節原文，逐條標註條號 |
| 10 | 個案練習 | 2–3 個臨床情境，含引導問題與參考答案 |
| 11 | 自我測驗 | 單選題＋詳解，對準專師甄審題型 |
| 12 | 參考文獻 | APA 7 格式，附 DOI 或 PMID |

跨癌別共用的內容放在 `handbook/00-shared/`（劑量計算、腫瘤急症、支持性照護、irAE），各章用連結引用，不重複寫。

## 3. 提示框（Callout）

用 GitHub alert 語法，GitHub 和網頁版都會渲染成彩色提示框：

| 語法 | 網頁版標籤 | 用途 |
|------|-----------|------|
| `> [!IMPORTANT]` | 考試重點 | 專師甄審常考、必背數字 |
| `> [!TIP]` | 比喻理解 | 用比喻講機轉或概念 |
| `> [!WARNING]` | 臨床警示 | 病人安全、致命副作用、常見錯誤 |
| `> [!NOTE]` | 院內規範 | 各院做法不同、需依院內規範調整的地方 |
| `> [!CAUTION]` | 待核對 | 尚未核對原文、或有時效性的資料 |

提示框第一行用粗體寫**這一框的主題**（不要重複「考試重點」這類類型名稱，網頁版會自動加上類型標籤），不使用 emoji。範例：

```markdown
> [!IMPORTANT]
> **EGFR 常見突變**
> EGFR exon 19 deletion 與 L858R 合計約占 EGFR 突變的 85–90%。
```

## 4. 證據與引用

- 每個治療建議要能回答「**根據什麼？**」：指引（NCCN／ESMO／台灣醫學會）＋關鍵試驗。
- 試驗寫法固定：**試驗名**（第一作者, 年份）— 族群；組別；主要指標結果（median、HR、95% CI）。
- 內文引用用 APA 7：（Soria et al., 2018）。文末參考文獻附 DOI 或 PMID。
- 有時效性的數字（流病統計、給付條件、藥證）要註明**資料年或公告日期**。
- 還沒核對原文的內容一律包在 `> [!CAUTION]` 裡，不可混入正文當成定論。

## 5. 健保給付表格式

依《全民健康保險藥品給付規定》第 9 節「抗癌瘤藥物」，每個藥物一列：

| 藥品 | 條號 | 給付適應症與條件 | 事前審查 | 療程／續用評估 | 停用條件 |
|------|------|----------------|---------|--------------|---------|

- 條號照原文寫（例如 9.xx.x），附**原文公告或修訂日期**。
- 「給付條件」要寫到能直接拿來對照病人的程度：病理、biomarker、線別、ECOG、前線用藥限制。
- 自費但指引建議的藥物另列一表，標明「健保未給付」。

## 6. 個案與測驗格式

- 個案：情境 → 引導問題 → 摺疊的參考答案。
- 測驗：單選題，選項 A–D，答案與詳解用摺疊區塊：

```markdown
**Q1.** 題幹……

A. ……　B. ……　C. ……　D. ……

<details>
<summary>答案與詳解</summary>

**答案：B**。詳解……

</details>
```

## 7. 版本標示

每章開頭用一個表格標示：指引版本、分期版次、健保規定版本、最後更新日期。內容依據改版時，同步更新這個表格。
