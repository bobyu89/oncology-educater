# 學習路徑

<!-- 這個檔案由 tools/build_site.py 依 handbook/learning-path.json 產生，請不要手動修改。 -->

照這個順序讀，前面的章節會先把後面要用的觀念講完。每一站最後有測驗；答對率到 80% 再往下走。

網頁版會記錄讀到哪裡、測驗答對幾題；在 GitHub 上讀的人可以把下面的清單複製到自己的筆記打勾。

## 第一站　先看全貌

**目標：** 知道抗癌藥物怎麼來、一位病人從發現腫瘤到決定治療會經過哪些步驟，之後每一章才知道自己在地圖的哪裡。

- [ ] [抗癌藥物總論：從發現到臨床](05-drugs/01-drug-development.md)：整章（約 79 分鐘）
- [ ] [體能狀態：ECOG 與 KPS](00-shared/01-chemo-basics.md)：本章重點、1. 體能狀態：ECOG 與 KPS（約 3 分鐘）
- [ ] 本站測驗：抗癌藥物總論 的自我測驗，答對率 80% 以上
