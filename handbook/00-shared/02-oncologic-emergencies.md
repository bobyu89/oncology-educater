## 本章重點

- **發燒性嗜中性球低下（FN）是「時間就是生命」**：分流後 **60 分鐘內**給第一劑經驗性抗生素，不要等報告。
- **TLS 重在預防**：高風險病人先水化、用 rasburicase；給 rasburicase 前確認 **G6PD**。
- **脊髓壓迫看的是「還能不能走」**：疑似 MSCC 且有神經學症狀或徵象就立刻給 dexamethasone（只有背痛、沒有神經學表現者不需常規給）、24 小時內做全脊椎 MRI。
- **上腔靜脈症候群多半不是「要立刻放射治療」的急症**：除非有喉頭水腫、腦水腫或血行動力不穩，**先拿到病理**。
- **低血鈉矯正有速限**：24 小時內上升不超過 10 mmol/L（高風險者 8 mmol/L），避免滲透性脫髓鞘。
- **雙特異性 T 細胞銜接抗體（如 tarlatamab）要會分 CRS 與 ICANS 等級**。
- **輸注中的嚴重反應：先停輸注、保留靜脈通路；符合 anaphylaxis 就立刻 epinephrine 肌肉注射**（成人 0.01 mg/kg，單次最多 0.5 mg，大腿前外側，5–15 分鐘可重複），抗組織胺與類固醇只是輔助。
- **惡性腸阻塞先分「能不能開」**：完全阻塞用 IV／SC 藥物，避免 metoclopramide 與瀉劑；**嗜中性球低下性小腸結腸炎**要用含厭氧菌覆蓋的廣效抗生素，不要用止瀉藥遮住症狀。
- **惡性肋膜積水先做大量穿刺看肺能不能復張**：可復張，IPC 或 talc 沾黏術二擇一；不能復張或沾黏失敗，IPC 優先。

## 1. 發燒性嗜中性球低下

### 1.1 辨識

**IDSA 定義（Freifeld et al., 2011）：**

- **發燒**：單次口溫 ≥ 38.3°C，或 ≥ 38.0°C 持續超過 1 小時。
- **嗜中性球低下**：ANC < 500/µL，或預期 48 小時內降到 < 500/µL。（ANC < 100/µL 稱為 profound neutropenia。）

**時間點**：多數細胞毒性化療的白血球最低點（nadir）約在給藥後 7–14 天。

> [!WARNING]
> **不發燒的敗血症**
> 正在使用類固醇的病人、老年人，感染時可能不發燒，只表現為低血壓、意識改變或倦怠。化療後 nadir 期出現這些變化，要以 FN 的態度處理。

### 1.2 立即處置（第一小時）

1. **分流後 60 分鐘內給第一劑經驗性抗生素**（Taplitz et al., 2018）。
2. 給抗生素前抽**血液培養至少 2 套**：周邊一套；有中心靜脈導管者，另從導管每個管腔各抽一套。抽不到不要拖延抗生素。
3. 同時抽 CBC/DC、生化（腎、肝、電解質）、lactate；依症狀做尿液檢查與培養、胸部 X 光、局部培養（痰、傷口、糞便）。
4. 評估生命徵象與敗血症；低血壓 → 依敗血症流程輸液、會診加護。

**經驗性抗生素（高風險、住院）：** 單一抗綠膿桿菌 β-lactam，例如 cefepime、piperacillin-tazobactam 或 carbapenem（meropenem、imipenem）。

**何時加上 vancomycin（不是常規）：** 血行動力不穩、懷疑導管感染、皮膚軟組織感染、肺炎、已知 MRSA 移生、血液培養報告革蘭氏陽性菌而尚未鑑定（Freifeld et al., 2011）。

### 1.3 風險分級：誰可以門診治療

**MASCC 風險指數**（Klastersky et al., 2000），總分 26 分，**≥ 21 分為低風險**：

| 項目 | 分數 |
|------|------|
| 疾病負擔：無症狀或輕微症狀 | 5 |
| 疾病負擔：中度症狀 | 3 |
| 無低血壓（收縮壓 > 90 mmHg） | 5 |
| 無慢性阻塞性肺病 | 4 |
| 實體腫瘤，或血液腫瘤但無先前黴菌感染 | 4 |
| 無需靜脈輸液的脫水 | 3 |
| 發燒時為門診病人 | 3 |
| 年齡 < 60 歲 | 2 |

（「疾病負擔」兩項擇一計分。）

**CISNE**（Clinical Index of Stable Febrile Neutropenia）用於「看起來穩定」的實體腫瘤病人：ECOG ≥ 2（2 分）、壓力性高血糖（2 分）、COPD（1 分）、慢性心血管疾病（1 分）、黏膜炎 ≥ Grade 2（1 分）、單核球 < 200/µL（1 分）；0 分低風險、1–2 分中風險、≥ 3 分高風險（Carmona-Bayonas et al., 2015）。

**ASCO/IDSA 2018 門診治療原則（Taplitz et al., 2018）：**

- 用臨床判斷搭配 MASCC 等工具篩選低風險病人，並考慮心理社會與交通等條件。
- 給藥後**至少觀察 4 小時**再離院。
- 口服經驗性治療：**fluoroquinolone ＋ amoxicillin/clavulanate**（盤尼西林過敏改 clindamycin）；若發燒前已在吃 fluoroquinolone 預防，則不適用。
- 治療 2–3 天仍未退燒者，重新評估並考慮住院。

### 1.4 後續

- 每日評估；48–72 小時重新檢視培養結果，依結果降階或調整。
- 高風險病人（預期嗜中性球低下總時間 > 7 天）使用經驗性抗生素 4–7 天後仍持續或再度發燒、找不到原因 → 考慮經驗性抗黴菌治療，並安排侵襲性黴菌感染檢查；低風險病人不建議常規經驗性抗黴菌治療（Freifeld et al., 2011）。
- 下一週期考慮 G-CSF 次級預防或減量，見[支持性照護](03-supportive-care.md)；G-CSF 的健保條件見 1.6。
- FN 病人出現腹痛、腹瀉或腹脹，要想到嗜中性球低下性小腸結腸炎，見第 11 節。

### 1.5 專師該開的 order（範例）

```
[FN 初始 order — 範例，依院內 FN 流程與抗生素政策調整]
- Vital signs q1h × 4 次，之後 q4h；I/O
- Blood culture × 2 sets（周邊 + 各 CVC lumen），抽完立即給抗生素
- CBC/DC、BUN/Cr、Na/K、AST/ALT、T-bil、lactate
- U/A + urine culture；CXR；依症狀加做 sputum / stool / wound culture
- Cefepime 2 g IV q8h（依腎功能調整）── 分流後 60 分鐘內給第一劑
- 若符合加 vancomycin 條件：依院內 TDM 劑量
- 保護性隔離／手部衛生衛教
```

> [!NOTE]
> **抗生素選擇依院內抗生素政策**
> 第一線抗生素、劑量與何時升級到 carbapenem，要依各院的抗生素管理政策與當地抗藥性資料（antibiogram）決定。

> [!IMPORTANT]
> **FN 必背**
> - 定義：口溫 ≥ 38.3°C 一次，或 ≥ 38.0°C 持續 1 小時；ANC < 500/µL 或預期 48 小時內 < 500/µL。
> - 抗生素：分流後 60 分鐘內；單一抗綠膿桿菌 β-lactam。
> - MASCC ≥ 21 分為低風險；門診口服 ciprofloxacin ＋ amoxicillin/clavulanate，觀察 ≥ 4 小時。

## 2. 腫瘤溶解症候群（TLS）

### 2.1 辨識：Cairo-Bishop 定義

**實驗室 TLS（LTLS）**：在治療開始前 3 天到開始後 7 天內，出現以下 **2 項以上**（Cairo & Bishop, 2004）：

| 項目 | 標準 |
|------|------|
| 尿酸 | ≥ 8 mg/dL，或比基線上升 25% |
| 鉀 | ≥ 6.0 mmol/L，或上升 25% |
| 磷 | ≥ 4.5 mg/dL（成人），或上升 25% |
| 鈣 | ≤ 7 mg/dL，或下降 25% |

**臨床 TLS（CTLS）**：LTLS 加上以下任一：肌酸酐 ≥ 1.5 × ULN、心律不整或猝死、癲癇。

### 2.2 誰是高風險

TLS 最常見於高增殖、高腫瘤負擔的血液腫瘤（如 Burkitt lymphoma、急性白血病）。實體腫瘤較少見，但在**腫瘤負擔大、對化療極敏感**（例如廣泛期小細胞肺癌）、**大範圍肝轉移、LDH 高、原本腎功能差**時仍可能發生（Cairo et al., 2010）。

### 2.3 預防與治療

依風險分級（Coiffier et al., 2008；Cairo et al., 2010）：

| 風險 | 處置 |
|------|------|
| 低 | 監測、適當水化，可加 allopurinol |
| 中 | 水化 ＋ allopurinol（已有高尿酸可用 rasburicase） |
| 高 | 積極水化 ＋ **rasburicase**；密切監測，必要時入加護病房 |

- **水化**：最高風險者靜脈輸液每日 2,500–3,000 mL/m²；充分水化後尿量仍不足，可加 loop diuretic，目標尿量至少 2 mL/kg/hr（Howard et al., 2011）；注意心衰竭病人。
- **不建議鹼化尿液**：鹼性尿液雖增加尿酸溶解度，卻降低磷酸鈣溶解度（Coiffier et al., 2008；Howard et al., 2011）。
- **Allopurinol**：抑制尿酸「生成」，對已存在的尿酸無效；需依腎功能調整。
- **Rasburicase**：把已存在的尿酸分解，數小時內降尿酸；**G6PD 缺乏者禁用**（會溶血、變性血紅素血症）。
- **高血鉀**：心電圖監測；calcium gluconate 穩定心肌、insulin ＋ glucose、β2 agonist、排鉀樹脂；嚴重或合併腎衰竭 → 透析。
- **低血鈣**：**只在有症狀時補鈣**，且用能緩解症狀的最低劑量（避免磷酸鈣沉積）（Howard et al., 2011）。
- **監測頻率**：高風險者開始治療後每 4–6 小時抽電解質、肌酸酐、尿酸並持續心電監測；中風險每 8–12 小時；低風險每日（Howard et al., 2011）。
- **腎衰竭、難治高鉀或高磷、體液過多** → 會診腎臟科評估透析。

> [!WARNING]
> **台灣臨床的兩個基因地雷**
> - **G6PD 缺乏**：台灣新生兒篩檢包含 G6PD，但成人病人不一定記得；給 rasburicase 前要查證（病史、新生兒篩檢紀錄或檢驗）。
> - **HLA-B\*5801**：漢人帶有 HLA-B\*5801 者使用 allopurinol，發生 SJS/TEN 等嚴重皮膚過敏的風險顯著升高（Hung et al., 2005）。開立 allopurinol 前確認是否已檢測，或依院內規範考慮替代藥物。

> [!NOTE]
> **Rasburicase 檢體處理**
> 使用 rasburicase 後，血液檢體中的 rasburicase 會在室溫下持續分解尿酸，造成尿酸假性偏低；多數醫院規定檢體需冰浴送檢。依院內檢驗科規範。

> [!TIP]
> **Allopurinol 與 rasburicase 的差別**
> Allopurinol 是「關水龍頭」：讓身體不再製造新的尿酸，但已經淹在地上的水不會消失。Rasburicase 是「拿抽水機抽水」：直接把已經存在的尿酸分解掉。TLS 已經發生時，光關水龍頭來不及。

### 2.4 專師該開的 order（高風險範例）

```
[TLS 高風險預防 — 範例]
- IV fluid 2,500–3,000 mL/m²/day（依心肺功能調整），目標 UO ≥ 2 mL/kg/hr；嚴格 I/O、每日體重
- Lab q4–6h（高風險）：K、P、Ca、uric acid、BUN/Cr、LDH
- ECG monitor（高鉀風險）
- 確認 G6PD 後：rasburicase（劑量依仿單／院內規範）
- 尿酸檢體依院內規定冰浴送檢
```

## 3. 上腔靜脈症候群（SVC syndrome）

### 3.1 辨識

- **成因**：惡性腫瘤壓迫或侵犯上腔靜脈，最常見為肺癌與淋巴瘤（依病例數，惡性病因中非小細胞肺癌約 50%、小細胞肺癌約 22%、淋巴瘤約 12%；小細胞肺癌多為中央型且常合併縱膈淋巴結腫大，罹患者發生 SVC 症候群的比例較高，但病例數最多的仍是非小細胞肺癌）；另有中心靜脈導管相關血栓（Wilson et al., 2007）。
- **症狀**：臉部、頸部、上肢腫脹，胸壁靜脈曲張，呼吸困難、咳嗽，平躺或彎腰加重；嚴重時喉頭水腫（喘鳴）、腦水腫（頭痛、意識混亂）。
- **檢查**：胸部顯影 CT。

**嚴重度分級（Yu et al., 2008）**：

| Grade | 描述 |
|-------|------|
| 0 | 影像有阻塞，無症狀 |
| 1 輕度 | 頭頸水腫、發紺、充血 |
| 2 中度 | 水腫造成功能受限（輕度吞嚥困難、咳嗽、視力或頭頸活動受影響） |
| 3 嚴重 | 輕中度腦水腫（頭痛、頭暈）或喉頭水腫，或心臟儲備受限 |
| 4 危及生命 | 明顯腦水腫（意識混亂、遲鈍）、明顯喉頭水腫（喘鳴）或血行動力不穩 |
| 5 | 死亡 |

### 3.2 立即處置

- **Grade 4（喘鳴、意識改變、血行動力不穩）**：保護呼吸道，緊急會診放射介入考慮**血管內支架**，症狀可在短時間內緩解（Yu et al., 2008）。
- **其他多數病人**：抬高床頭、給氧；**先取得組織診斷**再開始治療。
- 類固醇只用於淋巴瘤或放射治療相關水腫等特定情況；**未取病理前不要經驗性給類固醇或放射治療**，可能讓淋巴瘤的病理判讀失準。

### 3.3 後續

- 依病理治療原發腫瘤：小細胞肺癌、淋巴瘤對化療反應快；非小細胞肺癌常需放射治療或支架。
- 導管相關血栓：抗凝血，評估是否移除導管。

> [!IMPORTANT]
> **SVC 症候群的考點**
> 除非有喉頭水腫（喘鳴）、腦水腫或血行動力不穩，SVC 症候群通常有時間先做切片；緊急情況首選血管內支架。

> [!NOTE]
> **上肢給藥與抽血**
> SVC 阻塞時上肢靜脈回流差，部分醫院建議改由下肢建立靜脈通路，依院內規範。

## 4. 惡性脊髓壓迫（MSCC）

### 4.1 辨識

- **背痛**是最常見也最早出現的症狀，常在神經學症狀前數週出現；平躺、咳嗽、用力時加劇。
- 隨後出現下肢無力、感覺平面、大小便功能障礙（晚期表現）。
- **預後最重要的因子是「治療時是否還能走」**。

> [!WARNING]
> **癌症病人新出現的背痛，先當作脊髓壓迫處理**
> 等到大小便失禁、雙腿無力才發現，通常已無法恢復行走能力。已知骨轉移的病人新出現背痛，要主動做神經學檢查並安排 MRI。

### 4.2 立即處置

1. **Dexamethasone**：疑似 MSCC 且有神經學症狀或徵象（無力、感覺異常、大小便障礙）時就給，不等 MRI；只有背痛、沒有神經學表現者不需常規給予（嚴重疼痛或血液腫瘤時再考慮）。常見做法為 10 mg IV 負荷後每日約 16 mg 分次給予（如 4 mg q6h），劑量在各文獻與醫院間略有差異（Lawton et al., 2019）。極高劑量（96 mg）在早期試驗中改善行走率（Sørensen et al., 1994），但副作用較多，目前多不常規使用。
2. **全脊椎 MRI**：24 小時內完成（多處病灶常見）。
3. 會診**放射腫瘤科**與**骨科或神經外科**；評估脊椎穩定度。
4. 臥床期間的翻身、預防深部靜脈血栓、腸胃道保護、膀胱照護、疼痛控制。

### 4.3 手術或放射治療

- **Patchell 2005 試驗**：直接減壓手術＋術後放射治療 vs. 單獨放射治療，治療後能行走的比例 84% vs. 57%（OR 6.2），保留行走能力時間中位數 122 天 vs. 13 天（Patchell et al., 2005）。
- 手術適合：單一節段壓迫、脊椎不穩定、預期存活夠長、腫瘤對放射治療不敏感、尚未完全癱瘓太久的病人。
- 對放射治療敏感的腫瘤（如淋巴瘤、骨髓瘤、小細胞肺癌）或不適合手術者 → 放射治療為主。

### 4.4 專師該開的 order（範例）

```
[疑似 MSCC — 範例]
- Dexamethasone 10 mg IV stat，之後 4 mg IV q6h（依主治醫師決定）
- MRI whole spine with/without contrast（urgent，24 小時內）
- Consult：放射腫瘤科、骨科／神經外科
- 神經學評估 q4h（肌力、感覺平面、肛門張力、解尿情形）
- PPI 或 H2 blocker；血糖監測
- 疼痛控制；預防性抗凝血（無禁忌時）；便秘預防
```

## 5. 惡性高血鈣（Hypercalcemia of malignancy）

### 5.1 辨識

- **機轉**：最常見為腫瘤分泌 PTHrP 的體液性高血鈣（如鱗狀細胞癌）；其次為骨轉移的溶骨作用（如乳癌、多發性骨髓瘤）；少數為 calcitriol 過多（部分淋巴瘤）（Stewart, 2005）。
- **症狀**：口渴多尿、脫水、噁心、便秘、腹痛、肌肉無力、意識混亂、嗜睡；心電圖 QT 縮短。
- **校正血鈣**：校正 Ca（mg/dL）= 測得 Ca ＋ 0.8 ×（4.0 − 白蛋白 g/dL）。有條件時直接測離子鈣。

### 5.2 立即處置

1. **生理食鹽水**大量補液：高血鈣造成多尿與脫水，補液是第一步；依心肺功能調整速度。
2. **Calcitonin**：4 IU/kg SC 或 IM q12h，數小時內起效，但 48 小時左右會出現耐受性（tachyphylaxis），只作為「橋接」。
3. **Zoledronic acid** 4 mg IV（至少 15 分鐘輸注）：2–4 天起效，效果持續；優於 pamidronate（Major et al., 2001）。
4. **Denosumab**：Endocrine Society 2023 指引建議使用 denosumab 或靜脈 bisphosphonate，條件性建議**優先選 denosumab**；嚴重高血鈣可合併 calcitonin；bisphosphonate 無效時改用 denosumab（El-Hajj Fuleihan et al., 2023）。Bisphosphonate 治療後仍高血鈣的病人，denosumab 120 mg SC（第 1、8、15、29 天，之後每 4 週）可在 10 天內讓 64% 病人血鈣降到 ≤ 11.5 mg/dL（Hu et al., 2014）。
5. **類固醇**：用於 calcitriol 介導（如部分淋巴瘤）的高血鈣。
6. 停用會升高血鈣的藥物：thiazide、鈣片、維生素 D、lithium。
7. 腎衰竭或極嚴重高血鈣 → 考慮透析。

> [!IMPORTANT]
> **高血鈣的時間軸**
> - 生理食鹽水：立即
> - Calcitonin：數小時起效，約 48 小時後失效
> - Zoledronic acid／denosumab：2–4 天才起效，但效果持久
> 所以嚴重高血鈣要「三管齊下」：補液 ＋ calcitonin 先擋，bisphosphonate 或 denosumab 接手。

> [!WARNING]
> **利尿劑不是第一線**
> Loop diuretic 只用在補足容積後出現體液過多的病人；在脫水狀態下給利尿劑會讓腎功能更差、血鈣更高。

> [!TIP]
> **校正血鈣的道理**
> 血中約 40% 的鈣與蛋白質結合（大部分是白蛋白），約一半是有作用的游離鈣。白蛋白低時，總鈣看起來「正常」，但真正有作用的游離鈣其實偏高。公式就是把「被低白蛋白藏起來的鈣」加回去。

## 6. SIADH 與低血鈉

### 6.1 辨識

- **好發**：小細胞肺癌最常見；也見於頭頸癌等。化療藥（cisplatin、cyclophosphamide、vincristine 等）、鴉片類藥物、抗憂鬱劑、疼痛與噁心也會刺激 ADH。
- **SIADH 診斷條件**：低張性低血鈉（血漿滲透壓 < 275 mOsm/kg）、尿液滲透壓 > 100 mOsm/kg、尿鈉 > 30 mmol/L、臨床上容積正常、甲狀腺與腎上腺功能正常（Spasovski et al., 2014；Verbalis et al., 2013）。
- 要與 cisplatin 造成的**腎性失鹽**（容積不足）區分：兩者尿鈉都高，但失鹽者有脫水表現，治療方向相反。

### 6.2 立即處置

**有嚴重症狀（癲癇、意識障礙、嘔吐、呼吸窘迫）：**

- **3% NaCl 150 mL IV 20 分鐘**，可重複（通常最多 2–3 次），目標第一小時血鈉上升約 5 mmol/L（Spasovski et al., 2014）。
- 每 20 分鐘至每小時追蹤血鈉，症狀改善後停止高張食鹽水。

**矯正速度上限（防止滲透性脫髓鞘症候群, ODS）：**

| 指引 | 上限 |
|------|------|
| 歐洲指引（Spasovski et al., 2014） | 第一個 24 小時 ≤ 10 mmol/L，之後每 24 小時 ≤ 8 mmol/L |
| 美國專家共識（Verbalis et al., 2013） | 一般病人 24 小時 10–12 mmol/L；ODS 高風險者 8 mmol/L |

ODS 高風險：血鈉 ≤ 105 mmol/L、低血鉀、酒精使用、營養不良、肝病。

**無症狀或輕症（慢性）：** 限水（例如每日 800–1,000 mL）、口服鹽錠、治療原發腫瘤（小細胞肺癌化療後常改善）；難治者考慮 urea 或 tolvaptan（需住院起始、避免長期使用，注意肝毒性）。

> [!WARNING]
> **矯正過快比低血鈉本身更危險**
> 滲透性脫髓鞘可能在數天後才出現吞嚥困難、構音障礙、四肢癱瘓，嚴重者可致閉鎖症候群或死亡，部分存活者留下永久神經學後遺症（Sterns, 2015）。若 24 小時內矯正超過上限，需與腎臟科討論用 D5W 或 desmopressin 把血鈉拉回。

### 6.3 專師該開的 order（範例）

```
[有症狀的嚴重低血鈉 — 範例]
- 3% NaCl 150 mL IV over 20 min，完成後抽 Na；可重複 1–2 次
- Na q2–4h（初期），I/O，每日體重
- 同時抽：serum osm、urine osm、urine Na、TSH、AM cortisol、glucose
- 設定 24 小時血鈉上升上限並交班
```

## 7. 腦轉移合併顱內壓升高

### 7.1 辨識

清晨頭痛、噴射狀嘔吐、視乳突水腫、局部神經學缺損、癲癇、意識改變；以腦部 MRI（或急診 CT）確認。

### 7.2 立即處置

- **Dexamethasone**：輕度症狀建議起始 4–8 mg/day；中重度顱內壓升高症狀可用 16 mg/day 以上；症狀穩定後在 2 週以上逐漸減量（Ryken et al., 2010）。
- **有腦疝跡象**（意識快速下降、瞳孔不等大、Cushing 反應）：抬高床頭 30 度、mannitol 或高張食鹽水、緊急會診神經外科。
- **抗癲癇藥**：有癲癇發作者才使用；**從未發作者不建議常規預防性使用**；可優先選擇 levetiracetam（Walbert et al., 2021）。
- **無症狀、無占位效應的腦轉移**：證據不足以建議常規使用類固醇（Ryken et al., 2010）。

### 7.3 後續：局部治療

ASCO-SNO-ASTRO 指引（Vogelbaum et al., 2022）重點：

- **有症狀的腦轉移**，不論全身治療為何，都應接受局部治療（手術或放射治療）。
- 大型、有占位效應的腫瘤較能從手術獲益。
- 無症狀、且無全身治療選項的 1–4 個未切除腦轉移（小細胞肺癌除外）→ 單用立體定位放射手術（SRS alone）。
- 接受全腦放射治療者 → 合併 memantine 與海馬迴迴避技術（符合條件時）。
- 部分有中樞神經活性的標靶藥（例如 EGFR、ALK 抑制劑），對無症狀腦轉移可先觀察全身治療反應，詳見各癌別章節。

> [!NOTE]
> **長期類固醇的配套**
> Dexamethasone 使用超過數週時，依院內規範考慮腸胃道保護、血糖監測、PJP 預防（見 [irAE](04-irae.md#4-長期類固醇的配套措施) 的類固醇配套），並記得 B 肝再活化風險（見[化療基礎](01-chemo-basics.md#6-b-型肝炎篩檢與預防性抗病毒)）。

## 8. 惡性心包膜積液與心包膜填塞

### 8.1 辨識

- 常見於肺癌、乳癌、淋巴瘤。
- **Beck 三徵**：低血壓、頸靜脈怒張、心音遙遠。另有心搏過速、**奇脈**（吸氣時收縮壓下降 > 10 mmHg）。
- 心電圖：低電壓、電交替（electrical alternans）。
- **心臟超音波**是診斷首選：右心房、右心室舒張期塌陷。

### 8.2 立即處置

- 心包膜填塞是臨床診斷，**有血行動力影響時立即會診心臟科，做超音波導引心包膜穿刺引流**（Adler et al., 2015；Schulz-Menger et al., 2025）。
- 避免利尿劑與血管擴張劑（會進一步降低前負荷）；低容積時可謹慎補液作為暫時支持。
- 引流液送細胞學、生化、培養。

### 8.3 後續

惡性心包膜積液復發率高：可延長導管引流、心包膜開窗手術，並治療原發腫瘤。惡性肋膜積水的處置見第 12 節。

## 9. 細胞激素釋放症候群（CRS）與神經毒性（ICANS）

### 9.1 為什麼腫瘤科專師要會

除了 CAR-T，**雙特異性 T 細胞銜接抗體**（bispecific T-cell engager）也會引起 CRS 與 ICANS。肺癌領域的代表是治療小細胞肺癌的 **tarlatamab**（DLL3 × CD3），其他如血液腫瘤的 teclistamab 等。這類藥常採**階梯式起始劑量**（step-up dosing），並規定前幾劑後需在醫療機構監測。

### 9.2 ASTCT 分級（Lee et al., 2019）

**CRS**（發燒 ≥ 38°C 是診斷 CRS 的必要條件；分級依低血壓與缺氧中較嚴重者。已確診 CRS 後若給了退燒藥、tocilizumab 或類固醇，發燒可能被壓住：此時即使不發燒仍視為 CRS，後續分級改依低血壓與缺氧）：

| Grade | 發燒 | 低血壓 | 缺氧 |
|-------|------|--------|------|
| 1 | ≥ 38°C | 無 | 無 |
| 2 | ≥ 38°C | 不需升壓劑 | 低流量鼻導管（≤ 6 L/min） |
| 3 | ≥ 38°C | 需一種升壓劑（± vasopressin） | 高流量鼻導管（> 6 L/min）、面罩、非再吸入面罩或 Venturi |
| 4 | ≥ 38°C | 需多種升壓劑（vasopressin 除外） | 需正壓通氣（CPAP、BiPAP、插管） |

**ICANS** 以 **ICE 評分**（10 分）為核心：

| ICE 項目 | 分數 |
|---------|------|
| 定向感：年、月、城市、醫院 | 4 |
| 命名：說出 3 樣物品名稱 | 3 |
| 遵從指令（如「伸出兩根手指」） | 1 |
| 書寫：寫出一個完整句子 | 1 |
| 注意力：從 100 每次減 10 倒數 | 1 |

ICANS 分級：Grade 1 = ICE 7–9 分；Grade 2 = 3–6 分；Grade 3 = 0–2 分；Grade 4 = 無法喚醒、無法評估。另外合併意識程度、癲癇、運動功能、顱內壓與腦水腫等項目，取最嚴重者定級。

### 9.3 處置原則

- **所有 CRS**：先排除感染（抽血液培養，嗜中性球低下時依 FN 處理）、退燒、補液。
- **Grade 2 以上 CRS**：依產品仿單考慮 **tocilizumab**；合併類固醇（dexamethasone）。
- **Grade 3–4**：入加護病房；升壓劑與呼吸支持；類固醇劑量升高。
- **ICANS**：**以類固醇為主**（tocilizumab 不易通過血腦屏障）；Grade 3 以上入加護病房；評估癲癇。
- 依仿單決定暫停或停藥、重新給藥前的監測要求。

**美國仿單數字（已核對：Imdelltra Revised 9/2026；Actemra Revised 12/2025；Tecvayli Revised 3/2026）**

- 階梯劑量（靜脈輸注 1 小時）：Cycle 1 Day 1 為 1 mg，Day 8 與 Day 15 各 10 mg，之後每 2 週 10 mg，直到疾病惡化或無法耐受的毒性（Amgen, 2026）。
- Cycle 1 Day 1 與 Day 8 的併用藥：輸注前 1 小時內給 dexamethasone 8 mg IV（或同等劑量）；輸注完成後立即給 0.9% 生理食鹽水 1 L，於 2–4 小時內輸注。
- 監測：Cycle 1 Day 1 與 Day 8 從輸注開始起，在適當的醫療環境監測 6–8 小時；Cycle 1 Day 2 與 Day 9 要做病人評估（含生命徵象）；Day 1 與 Day 8 給藥後共 48 小時內，病人需待在距離適當醫療機構 1 小時內的地方，並有照顧者陪同。Day 15 與 Cycle 2 的觀察為 6–8 小時，Cycle 3–4 為 3–4 小時，Cycle 5 起為 2 小時；除非先前出現 Grade ≥ 2 CRS、ICANS 或神經毒性，否則不需延長醫療機構內監測。
- CRS 處置（仿單 Table 5，ASTCT 分級）：Grade 1 給症狀處置（如 acetaminophen），可考慮 dexamethasone 4–10 mg PO/IV；Grade 2 建議住院至少 24 小時並做心電監視與血氧監測，可考慮 dexamethasone 8 mg PO/IV 與 tocilizumab；Grade 3 在 Grade 2 處置之上加加護監測與 dexamethasone 8 mg IV q8h（最多 3 劑），仿單為「建議」tocilizumab；Grade 4 永久停藥，處置同 Grade 3。
- ICANS 處置（Table 6）：Grade 1 為支持性處置；Grade 2 為 dexamethasone 8–10 mg PO/IV（可每 12 小時重複）或 methylprednisolone 1 mg/kg IV q12h（症狀惡化時）；Grade 3 為 dexamethasone 10 mg IV q6h 或 methylprednisolone 1 mg/kg IV q12h，建議加護監測；Grade 4 永久停藥，使用高劑量類固醇（例如 methylprednisolone 1,000 mg/day 分次 IV，連續 3 天）。
- Tocilizumab：tarlatamab 仿單對 CRS Grade 2 寫「考慮」、Grade 3–4 寫「建議」，但**沒有給劑量**。Actemra 仿單列有劑量的 CRS 適應症是 CAR T 細胞誘發的嚴重或危及生命 CRS：體重 ≥ 30 kg 為 8 mg/kg，靜脈輸注 60 分鐘，單次不超過 800 mg；改善不足時最多再給 3 劑，間隔至少 8 小時（Genentech, 2025a）。雙特異性抗體引起的 CRS 不在該適應症內，實際劑量依院內流程。
- 產品之間確實不同：teclistamab（Tecvayli，皮下注射，美國仿單 Revised 3/2026）單藥以 0.06 mg/kg（Day 1）、0.3 mg/kg（Day 4）、1.5 mg/kg（Day 7）階梯式起始；階梯劑量 1 與階梯劑量 2 之後各要住院 48 小時，第一個治療劑量（Day 7）之後則是留在醫療機構附近並每日監測 48 小時；階梯期內的三劑，每劑前 1–3 小時都要給 dexamethasone 16 mg（Janssen Biotech, 2026）。

> [!CAUTION]
> **待核對：台灣核准仿單與其他雙特異性抗體**
> 上列數字來自美國 FDA 仿單。本手冊尚未取得 TFDA 核准的 tarlatamab（安泰適）仿單，無法確認台灣版的劑量與監測要求是否相同；除 teclistamab 外，elranatamab、glofitamab、epcoritamab、blinatumomab 等產品的仿單也未逐一核對。Tocilizumab 用於雙特異性抗體 CRS 的劑量，tarlatamab 與 teclistamab 的仿單都沒有給。仿單會隨上市後資料更新，開立前請以最新仿單與院內流程為準。

> [!TIP]
> **CRS 與 ICANS 的區分**
> CRS 是「全身發炎風暴」：發燒、低血壓、缺氧，用 IL-6 阻斷劑（tocilizumab）滅火。ICANS 是「腦部受波及」：字寫不出來、叫不出東西名字、意識變差，主要靠類固醇。CRS 常先出現，ICANS 可同時或隨後出現。

## 10. 輸注反應、過敏反應與過敏性休克

### 10.1 結論先行

- 輸注中出現新症狀（發燒、寒顫、胸悶、喘、癢、血壓掉）：**先停輸注、保留靜脈通路、評估氣道／呼吸／循環與意識**，再分類。
- 符合 anaphylaxis（過敏性休克）就**立刻肌肉注射 epinephrine**：成人 0.01 mg/kg、單次最多 0.5 mg（1 mg/mL 溶液 0.5 mL），打在**大腿前外側**，症狀未改善**每 5–15 分鐘可重複**（Cardona et al., 2020）。抗組織胺與類固醇是輔助藥，**不能取代、也不該先於 epinephrine**。
- 用 CTCAE v5.0 分級；多數單株抗體的 Grade 1–2 輸注反應降速或暫停、處置後可以繼續；Grade 3–4 或 anaphylaxis，仿單多半要求永久停藥，是否改用其他藥、減敏或再挑戰，由主治醫師與過敏免疫科決定。
- 紫杉醇類反應多出現在第 1–2 次暴露；carboplatin 反應多出現在已經用了很多個週期之後；oxaliplatin 則「任何一個週期都可能發生」，目前美國仿單列有 HSR／anaphylaxis 的加框警語。

> [!IMPORTANT]
> **第一個動作的考點**
> 輸注中疑似嚴重反應，第一步是「停止輸注、保留靜脈通路」，第二步是「依 ABC 評估並盡早給 epinephrine IM」。靜脈推注 epinephrine 不是初始治療（可能引發致命心律不整），難治性反應才由有經驗的醫師以幫浦持續輸注（Cardona et al., 2020）。

### 10.2 四種容易搞混的反應

| 類型 | 典型時機 | 臨床線索 | 本手冊常見藥物 | 再次暴露 |
|------|---------|---------|--------------|---------|
| 輸注反應（infusion-related reaction, IRR） | 多在第一次輸注；症狀常在輸注開始後數十分鐘到數小時內出現（amivantamab 中位數約 1 小時，範圍 0.1–18 小時） | 發燒、寒顫、潮紅、胸悶、呼吸困難、低血壓；放慢速度、給對症藥物後多可緩解 | rituximab、cetuximab、trastuzumab、amivantamab | 後續輸注多半明顯減少（amivantamab 單藥：Week 1 Day 1 為 65%，Day 2 為 3.4%，Week 2 為 0.4%） |
| 過敏反應（hypersensitivity reaction, HSR） | 已暴露多次之後；數分鐘內 | 蕁麻疹、全身或手腳掌發癢、支氣管痙攣、低血壓 | carboplatin、oxaliplatin | 再給容易復發；多半需換藥或減敏 |
| 紫杉醇類反應 | 第 1 或第 2 次暴露（Weiss et al., 1990） | 呼吸困難、低血壓、支氣管痙攣、蕁麻疹、紅疹 | paclitaxel、docetaxel | 預防用藥後多數可再挑戰成功（Banerji et al., 2014）；嚴重者不可再給 |
| Anaphylaxis（過敏性休克） | 分鐘到數小時 | 皮膚黏膜症狀加上呼吸或循環受影響；約 10–20% 沒有皮膚表現 | 以上任何藥物 | 依病因與嚴重度而定 |
| 細胞激素釋放症候群（CRS） | T 細胞銜接抗體給藥後，常見於階梯式起始劑量期間（見第 9 節） | 發燒 ≥ 38°C 為必要條件，合併低血壓、缺氧 | tarlatamab 等 | 見第 9 節 |

- **IRR 與 HSR 在床邊常常分不開**，兩者也可以同時存在；處置以「嚴重度」為準，不要等分類清楚才開始處理。
- CTCAE v5.0 的規則：與輸注相關的過敏症狀，用「Infusion related reaction」回報，**不要同時回報 Allergic reaction**。
- **CRS 的關鍵是發燒**：沒有發燒，單純蕁麻疹加喘，優先想過敏；使用雙特異性抗體後發燒＋低血壓＋缺氧，優先想 CRS（分級見第 9 節）。

> [!TIP]
> **IRR 與 HSR 的比喻**
> IRR 像「第一次進門的訪客按到太大聲的門鈴」：藥物一進入體內就觸動免疫細胞發出訊號，放慢腳步、事先安撫（預防用藥）通常就能壓住，下一次多半安靜很多。HSR 像「保全已經認得你的臉」：身體曾經見過這個藥並建立了警戒，再次出現就立刻全面動員，所以愈多週期愈危險（carboplatin）。Anaphylaxis 則是警報升級成多系統的全面警戒。

### 10.3 Anaphylaxis 的診斷標準

WAO 2020 修訂版（Cardona et al., 2020）：符合**任一項**即高度可能是 anaphylaxis：

1. 急性發作（數分鐘到數小時），**皮膚或黏膜**同時受影響（全身蕁麻疹、癢、潮紅、嘴唇舌頭腫），**且至少一項**：呼吸受影響（呼吸困難、喘鳴、喉鳴、PEF 下降、缺氧）、血壓下降或器官灌流不足的症狀（昏厥、癱軟、失禁）、嚴重腸胃症狀（劇烈絞痛、反覆嘔吐，尤其是接觸非食物過敏原）。
2. 接觸已知或高度可能的過敏原後急性出現**低血壓、支氣管痙攣或喉部症狀**，即使沒有皮膚表現。

低血壓的定義：成人收縮壓 < 90 mmHg，或比基線下降超過 30%。

> [!WARNING]
> **沒有蕁麻疹不代表不是 anaphylaxis**
> 皮膚症狀在約 10–20% 的 anaphylaxis 並不存在，容易延誤辨識（Cardona et al., 2020）。輸注中突然低血壓、喘鳴或喉部緊縮，即使皮膚正常也要按 anaphylaxis 處理。

### 10.4 CTCAE v5.0 分級

| 項目 | Grade 1 | Grade 2 | Grade 3 | Grade 4 |
|------|---------|---------|---------|---------|
| Infusion related reaction | 輕微短暫；不需中斷輸注，不需處置 | 需處置或中斷輸注，但對症狀治療（抗組織胺、NSAIDs、麻醉性止痛藥、靜脈輸液）反應迅速；預防用藥需 ≤ 24 小時 | 反應延長（對症狀治療或短暫中斷輸注反應不佳）；症狀改善後再度出現；因後遺症需住院 | 危及生命，需緊急處置 |
| Allergic reaction | 不需全身性處置 | 需口服處置 | 支氣管痙攣；因後遺症需住院；需靜脈處置 | 危及生命，需緊急處置 |
| Anaphylaxis | — | — | 有症狀的支氣管痙攣（可伴蕁麻疹）、需非口服處置；過敏相關水腫或血管水腫；低血壓 | 危及生命，需緊急處置 |

Grade 5 皆為死亡（National Cancer Institute, 2017）。

### 10.5 常見藥物：反應特性、前置用藥與輸注重點

| 藥物 | 反應特性（仿單） | 前置用藥 | 輸注與再給藥重點 |
|------|----------------|---------|----------------|
| paclitaxel | 加框警語：anaphylaxis 與嚴重 HSR 發生於 2–4% 的受試者，有前置用藥仍有致死案例（Alembic Pharmaceuticals, 2024） | **所有病人**：dexamethasone 20 mg PO（約輸注前 12 與 6 小時）；diphenhydramine（或同類）50 mg IV（前 30–60 分鐘）；H2 blocker（仿單列 cimetidine 300 mg 或 ranitidine 50 mg IV，前 30–60 分鐘） | 嚴重 HSR 者不可再挑戰；溶劑 Cremophor EL 被認為可能參與，機轉未明（Weiss et al., 1990） |
| docetaxel | 加框警語：有 dexamethasone 前置用藥仍發生嚴重 HSR；對 docetaxel 或 polysorbate 80 製劑有嚴重過敏史者禁用（Hospira, 2025） | 口服 dexamethasone 16 mg/日（8 mg BID）共 3 天，從輸注前 1 天開始 | HSR 發生要立即停止輸注並處置 |
| carboplatin | 加框警語：anaphylactic-like reaction 可在數分鐘內發生；曾接觸鉑類者風險增加（Apotex, 2024）。Markman 病例系列：首次反應的鉑類療程數中位數為第 8 次（範圍 6–21），約一半在藥量輸注超過一半後才發作（Markman et al., 1999） | 無常規前置用藥 | 多數有 carboplatin HSR 的病人沒有再挑戰（Banerji et al., 2014）；Markman 系列 3 例再挑戰僅 1 例成功；要繼續鉑類需過敏科評估（見 10.7） |
| oxaliplatin | 加框警語：嚴重與致命的 HSR（含 anaphylaxis）可在數分鐘內、**任何週期**發生；對 oxaliplatin 或其他鉑類有 HSR 病史者禁忌（Meitheal, 2024） | 無常規前置用藥 | 仿單：發生 HSR 立即且永久停藥並處置 |
| rituximab | 加框警語：可致命的 IRR，輸注後 24 小時內曾有死亡，約 80% 的致命反應發生在第一次輸注（Genentech, 2025b） | 每次輸注前給 acetaminophen 與抗組織胺 | 第一次：起始 50 mg/hr，無毒性則每 30 分鐘增加 50 mg/hr，最高 400 mg/hr；之後：起始 100 mg/hr，每 30 分鐘增加 100 mg/hr，最高 400 mg/hr；重度反應停止輸注，Grade 3–4 給予醫療處置 |
| cetuximab | 加框警語：嚴重甚至致命的輸注反應；臨床試驗 1,373 人中任何級別 8.4%、Grade 3–4 為 2.2%；有蜱叮咬、紅肉過敏或抗 galactose-α-1,3-galactose IgE 者 anaphylaxis 風險可能增加（ImClone, 2026） | 第一劑前 30–60 分鐘靜脈給 H1 antagonist，後續劑量視需要 | 初劑 400 mg/m² 輸注 120 分鐘，之後每週 250 mg/m² 輸注 60 分鐘；Grade 1–2 降低輸注速率 50%，Grade 3–4 立即且永久停用 |
| trastuzumab | 加框警語：嚴重且可致命的輸注反應，症狀多出現在輸注當下或 24 小時內（Genentech, 2026） | 依院內規範 | 輕中度降低輸注速率；呼吸困難或明顯低血壓要中斷輸注並監測到症狀完全消失；anaphylaxis、血管水腫、間質性肺炎或 ARDS 要永久停藥；嚴重反應後是否能再給缺乏資料，有人預先給抗組織胺或類固醇後仍復發 |
| amivantamab | MARIPOSA（併用 lazertinib）IRR 63%（Grade 3 為 5%、Grade 4 為 1%）；單藥 CHRYSALIS 為 66%（Janssen Biotech, 2025） | 首劑前 2 天起口服 dexamethasone 8 mg BID；Day 1 再給 dexamethasone 20 mg IV、diphenhydramine 25–50 mg 與 acetaminophen 650–1,000 mg；Day 2 給 dexamethasone 10 mg IV 與同樣的抗組織胺與 acetaminophen；之後每次仍給抗組織胺等預防用藥（細節以仿單 Table 5 為準） | 首劑拆成 Day 1 與 Day 2 兩天輸注；Week 1 與 Week 2 經周邊靜脈給藥；疑似 IRR 立即中斷輸注，依嚴重度減速或永久停藥 |

> [!NOTE]
> **前置用藥與 H2 blocker 的選擇依院內規範**
> 上表是美國仿單的寫法。paclitaxel 仿單列的是 cimetidine 或 ranitidine，實際使用哪一種 H2 blocker、劑量與給藥途徑，依院內藥典與化療處方模板（order set）；口服與靜脈前置用藥的給藥時間要排進病人的就醫流程，避免「藥還沒吃就已開始輸注」。

> [!NOTE]
> **各藥的健保給付不在本節**
> 本節只談輸注反應的處置。rituximab、cetuximab、trastuzumab、amivantamab 的給付條件見各癌別章的第 9 段；藥證、健保給付與院內藥典是三件不同的事。完整的藥物別處置也可參考 ESMO 輸注反應指引（Roselló et al., 2017）。

### 10.6 床邊處置流程

**所有疑似嚴重反應（Grade 3 以上或 anaphylaxis）的步驟**（Cardona et al., 2020；Shaker et al., 2020）：

1. **停止可疑藥物**：立即停止輸注，呼叫協助，不要離開病人。
2. **保留靜脈通路**：把含藥的輸注管路與病人分離，換上新的管路與 0.9% NaCl 維持通路；成人建立大口徑靜脈通路（14 或 16 號）。
3. **評估 ABC 與意識、皮膚**，並在短間隔內重複量血壓、心率、SpO2 與意識。
4. **姿勢**：多數病人平躺；有呼吸窘迫者讓病人採坐姿；意識不清用復甦姿勢；孕婦採左側半臥。抬高下肢（Trendelenburg）的好處有爭議。
5. **Epinephrine IM**：0.01 mg/kg，單次最多 0.5 mg（1 mg/mL 取 0.5 mL），注射於大腿前外側（股外側肌），症狀未改善每 5–15 分鐘重複（Cardona et al., 2020）。美國 Adrenalin 仿單的成人寫法為 0.3–0.5 mg IM 或 SC，每 5–10 分鐘視需要重複（Par Health, 2026）。
6. **氧氣**：呼吸窘迫者與需要再次給 epinephrine 者，給高流量氧氣（盡量 100%，非再吸入面罩）。
7. **輸液**：心血管不穩者給晶體溶液 20 mL/kg 快速輸注。
8. **輔助藥物**：支氣管痙攣可吸入 salbutamol 等短效 β2 agonist，但**不能取代**反覆給 IM epinephrine；上呼吸道阻塞可考慮噴霧 epinephrine；H1 antihistamine 只有緩解皮膚症狀的角色，部分指引將它列為第三線；glucocorticoid 在急性期的益處不明，常規使用有爭議；服用 β-blocker 而對 epinephrine 反應不佳者，可考慮 glucagon（Cardona et al., 2020）。
9. **難治性反應**：多次 IM epinephrine 無效，由有經驗的醫師在監測下以幫浦靜脈持續輸注 epinephrine，並啟動加護病房與急救團隊；需要時進行心肺復甦（Cardona et al., 2020）。
10. **留檢體**：EAACI 建議以臨床標準辨識 anaphylaxis，並抽血供事後測量 tryptase（Muraro et al., 2022）；採血時間點依檢驗科規範。
11. **觀察雙相反應**：見 10.8。

**輕中度 IRR（Grade 1–2）的處理邏輯**：

| CTCAE 級別 | 第一步 | 能否繼續 |
|-----------|-------|---------|
| Grade 1 | 可不中斷或短暫減速，密切監測生命徵象 | 可繼續 |
| Grade 2 | 暫停輸注，給對症藥物（抗組織胺、acetaminophen 等）；症狀緩解後以較慢速度重新開始（cetuximab 仿單：降低輸注速率 50%；trastuzumab 仿單：輕中度反應降低輸注速率） | 多數可繼續，之後加強前置用藥 |
| Grade 3–4 | 停止輸注，並依上述 anaphylaxis 流程處置；rituximab 仿單：重度反應停止輸注並給予醫療處置；cetuximab 仿單：Grade 3–4 立即且永久停用 | 多數藥物永久停藥；是否改用其他藥、減敏或再挑戰，由主治醫師與過敏科決定 |

> [!WARNING]
> **三個常見的致命錯誤**
> - 先給 diphenhydramine 觀察一下，沒有立刻給 epinephrine：抗組織胺不能逆轉低血壓與支氣管痙攣，只是延誤。
> - 為了「方便」把 epinephrine 靜脈快速推注：成人 IV bolus 可能引發致命心律不整，初始治療走 IM。
> - 症狀緩解後讓病人直接回家：雙相反應的中位發生時間為 11 小時（Lee et al., 2015）。

> [!NOTE]
> **反應處理車（急救包）與院內流程**
> 化療室是否固定備有 1 mg/mL epinephrine 針劑、氧氣、面罩、抽吸、輸液、急救藥品，以及誰負責呼叫急救團隊，依各院「輸注反應／過敏性休克」流程。專師應先確認所在單位的急救包位置與有效期限，並熟悉啟動流程。管路與剩餘藥液的處置方式（例如保留給藥師調查）也依院內規範。

### 10.7 再給藥、減敏與再挑戰的原則

**先判斷反應的類型與嚴重度，再決定下一步：**

| 情況 | 原則 |
|------|------|
| 單株抗體的 Grade 1–2 IRR | 處置後降速繼續，下一次加強前置用藥；後續暴露通常較少再發 |
| paclitaxel 的輕中度 HSR | 症狀處置後，以預防用藥與較慢速度多半可再挑戰；Banerji 病例系列中多數紫杉醇 HSR 的病人再挑戰成功（Banerji et al., 2014）。docetaxel 的再挑戰，本手冊沒有查證到對應資料 |
| paclitaxel 的嚴重 HSR | 仿單：嚴重 HSR 者不可再挑戰（Alembic Pharmaceuticals, 2024） |
| carboplatin／oxaliplatin 的 HSR | 多數不再挑戰（Banerji et al., 2014）；oxaliplatin 仿單為立即且永久停藥。若鉑類仍是最佳選擇，轉介過敏免疫科評估 |
| 嚴重遲發型皮膚反應（SJS/TEN、DRESS）或血清病 | 不在快速減敏的建議適用範圍（EAACI 立場僅支持用於輕微、未併發的遲發型反應）；能否再用該藥由專科判斷（Vega et al., 2021 引述） |

**快速藥物減敏（rapid drug desensitization, RDD）是什麼：**

- 以逐步提高藥物濃度與輸注速度的方式，讓病人「暫時耐受」過敏原，完成完整劑量；每次再給藥都要重新進行（Castells et al., 2008）。
- Brigham and Women's Hospital 的標準流程為三袋溶液、12 個步驟，每個步驟固定間隔 15 分鐘（最後一步除外），劑量大約逐步增加 2–2.5 倍，總時間約 5–6 小時（Vega et al., 2021 描述該流程）。
- 證據：98 位病人、413 次減敏，94% 只有輕微或沒有反應，沒有危及生命的反應或死亡，所有病人都完成完整目標劑量（Castells et al., 2008）；後續 2,177 次減敏（370 位病人）中 93% 沒有或只有輕微反應，7% 為中重度但不影響完成治療，沒有死亡；風險分層後門診進行的比例由 81% 提高到 98%；carboplatin 過敏的卵巢癌病人以 RDD 給藥，療效不輸標準給藥（Sloane et al., 2016）。
- EAACI 立場文件建議 RDD 用於立即型 HSR 與輕微、未併發的遲發型反應（Pagani et al., 2022；Vega et al., 2021 引述）。

> [!WARNING]
> **減敏不是專師可以自行「慢慢滴看看」的操作**
> 減敏由過敏免疫科與腫瘤科共同決定，需要事先擬定個別化流程、同意書、監測環境與急救資源（過敏專科醫師與受訓護理師、可立即啟動急救）。對沒有專科評估的病人，「降速再滴」可能引發更嚴重的反應。

### 10.8 觀察期與雙相反應

- **雙相反應**（biphasic reaction）：症狀在初步緩解後，沒有再次接觸過敏原的情況下又出現。27 個觀察性研究的整合分析：發作時間中位數 11 小時（範圍 0.2–72 小時）；初始就有低血壓的病人風險較高；作者建議依個別特徵調整觀察時間（Lee et al., 2015）。
- 嚴重 anaphylaxis 與需要重複給 epinephrine 者是雙相反應的危險因子；**抗組織胺與類固醇不能可靠地預防雙相反應**；所有病人在症狀完全緩解前都要持續觀察（Shaker et al., 2020）。
- 約有一半的雙相反應發生在 6–12 小時內，目前對觀察時間沒有一致的共識（Cardona et al., 2020）。因此**觀察多久要由醫師依嚴重度決定**，嚴重反應、需要多劑 epinephrine 或低血壓者通常需要延長觀察或住院。
- 離開前的衛教：說明可能再發、再次出現喘、腫脹、頭暈或蕁麻疹要立刻回急診；trastuzumab 的輸注反應可在 24 小時內出現，rituximab 曾有 24 小時內的死亡案例，這類藥物的返家衛教要特別強調。

> [!NOTE]
> **觀察時間與住院門檻依院內規範**
> 國際指引沒有統一的觀察小時數。各院多自訂「最低觀察時間」與「何時收住院或加護病房」，專師開立觀察 order 前先確認院內標準，並把決定與理由寫進病歷。

### 10.9 病歷紀錄與通報

**病歷紀錄（SOAP）建議包含：**

- 藥名（含批號）、週期、輸注速率、反應發生在輸注開始後幾分鐘、已輸注多少。
- 症狀與生命徵象的時序（血壓、心率、SpO2、體溫、意識）、CTCAE 分級。
- 處置的藥名、劑量、途徑與時間，以及對處置的反應。
- 下一步決定（永久停藥、降速、加強前置用藥、轉介過敏科減敏）、已告知病人與家屬的內容。
- **更新過敏警示**，讓下一次開立化療 order 的人和藥師看得到。

**通報：**

- 院內不良事件與藥物不良反應通報，依院內流程。
- 法源：《藥事法》第 45 條之 1 規定，醫療機構、藥局及藥商對於因藥物所引起的嚴重不良反應，應行通報；方式、內容與其他應遵行事項，由中央衛生主管機關以辦法定之。

- 授權辦法為《藥品嚴重不良反應通報辦法》（衛生福利部，113 年 3 月 28 日修正，114 年 1 月 1 日施行）。醫療機構、藥局知悉嚴重不良反應時，要到中央衛生主管機關指定的網路系統填表通報；必要時可先以口頭、電話、傳真或電子郵件通報，但仍須在期限內完成網路通報（第 3 條；衛生福利部, 2024）。
- **嚴重不良反應**指使用藥品後發生下列情形之一：死亡、危及生命、永久性殘疾、胎兒或嬰兒先天性畸形、病人住院或延長住院時間、其他可能導致永久性傷害的併發症（第 2 條）。
- **醫療機構與藥局的通報期限**，自知悉之次日起算：死亡或危及生命者 **7 日內**；其餘四款（永久性殘疾、先天性畸形、住院或延長住院、其他可能導致永久性傷害的併發症）**30 日內**（第 6 條）。藥商為知悉通報事由之次日起 15 日內（第 7 條）。
- 輸注反應或 anaphylaxis 是否符合上述任一款（例如危及生命、住院），依臨床判斷；院內通報窗口與表單依藥劑部流程。條文改版後，以全國法規資料庫的現行版本為準。

### 10.10 專師該開的 order（範例）

```
[疑似嚴重輸注反應／anaphylaxis — 範例，依院內急救流程調整]
- 立即停止輸注；換新管路接 0.9% NaCl 維持靜脈通路；通知主治醫師並呼叫協助
- Vital signs、SpO2、意識：初期短間隔反覆評估（依院內急救流程），穩定後逐步拉長；持續心電監視
- Epinephrine 1 mg/mL（1:1000）0.5 mg（0.5 mL）IM，大腿前外側
  （成人 0.01 mg/kg，單次上限 0.5 mg）；症狀未改善每 5–15 分鐘可重複
- O2：高流量，非再吸入面罩，至 SpO2 穩定
- 0.9% NaCl 20 mL/kg 快速輸注（低血壓／灌流不足時）
- 支氣管痙攣：吸入短效 β2 agonist（不取代 epinephrine）
- 輔助藥（醫師決定）：H1 blocker（緩解皮膚症狀）、glucocorticoid；β-blocker 使用者反應不佳考慮 glucagon
```

## 11. 惡性腸阻塞與嗜中性球低下性小腸結腸炎

### 11.1 結論先行

- **惡性腸阻塞（MBO）先分「能不能開」**：腹膜擴散、體能差、大量腹水是手術的不良預後條件；單一位置的大腸阻塞優先考慮支架；其餘多數以 NPO、止吐、抗分泌與止痛的保守治療為主，必要時用減壓胃造口取代長期放置 NG tube。
- **出現腹膜徵象（反彈痛、肌強直）先懷疑穿孔或缺血**，這不是保守治療的對象，立刻通知外科。
- **嗜中性球低下性小腸結腸炎（neutropenic enterocolitis, NE；又稱 typhlitis）= 嗜中性球低下 + 發燒 + 腹痛 + CT 腸壁增厚 > 4 mm**。治療是 FN 流程加上**含厭氧菌覆蓋的廣效抗生素**、腸道休息；多數人不需要手術。
- **NE 病人不要用止瀉藥或常規鴉片類遮住腹痛與腹瀉的變化**，會延誤穿孔等併發症的判斷。

> [!IMPORTANT]
> **兩個急症的考點**
> - MBO 的完全阻塞：藥物改走靜脈或皮下；避免 metoclopramide 與瀉劑；haloperidol 是完全阻塞較常用的止吐藥（Madariaga et al., 2022）。
> - NE：FN 的腹痛不要只當成化療腸胃道副作用；抗生素要含厭氧菌覆蓋（piperacillin-tazobactam 或 carbapenem 單用，或 cefepime／ceftazidime 加 metronidazole），穿孔、藥物治療下仍無法控制的出血、膿瘍等才是手術適應症（Rodrigues et al., 2017）。

### 11.2 MBO：定義、成因與評估

**定義**（Anthony et al., 2007；MASCC 沿用，見 Madariaga et al., 2022）需同時符合：

1. 臨床上有腸阻塞的證據（病史、理學檢查或影像）；
2. 阻塞位置在 Treitz 韌帶以遠（遠端十二指腸以下）；
3. 原發於腹腔內且無法治癒的癌症，或腹腔外原發癌但已有明確的腹腔內病灶。

**誰會發生**：進展期癌症病人都可能，尤其是大腸與婦科惡性腫瘤（Davis et al., 2021）。胃出口阻塞（例如胰臟癌或胃癌）不符合上述「Treitz 韌帶以遠」的條件，但支架、胃空腸吻合與減壓的處理原則相近，見 11.4。

**評估重點：**

- 病史與理學檢查：嘔吐型態、排氣排便、腹脹、腸音、直腸指診（排除糞塊嵌塞）、**腹膜徵象**。
- **腹部骨盆 CT 是決定原因與可行介入的關鍵影像**（Ripamonti et al., 2008）；放置大腸支架前，ESGE 建議先完成顯影 CT（van Hooft et al., 2020）。
- 判斷是部分或完全阻塞，是單一位置或多處，有無穿孔、缺血、大量腹水與腹膜擴散。
- 電解質與腎功能（嘔吐與脫水）。

> [!WARNING]
> **腹膜徵象、發燒、心跳過速：先當外科急症**
> 穿孔時不適合放置減壓管或支架（Madariaga et al., 2022；van Hooft et al., 2020）。這時的「保守治療」只是等待手術評估的橋接，要同時通知外科與主治醫師。

> [!TIP]
> **把 MBO 想成被塞住的下水道**
> 阻塞處上游的水（腸液）一直在進來，所以才會一直脹、一直吐。NPO 與抗分泌藥像「把水龍頭關小」，NG tube 或減壓胃造口像「在上游抽水」，支架或手術則是「把管子疏通或繞道」。止吐藥只是讓感覺沒那麼噁心，並不能讓管子通。

### 11.3 MBO：保守治療

| 目的 | 做法 | 重點與證據 |
|------|------|-----------|
| 腸道休息 | **NPO**；阻塞緩解後依症狀緩慢、分級恢復飲食（清流質、全流質、低纖軟質，再到低纖正常質地） | MASCC：初診 MBO 先 NPO（Madariaga et al., 2022，證據等級 IV、B） |
| 輸液 | 依脫水程度與預後個別化，避免過量 | 靜脈輸液不能預防或改善口乾口渴，也不增加存活；過量可造成液體負荷過重、周邊與肺水腫（Madariaga et al., 2022）。Currow 試驗的標準支持療法含輸液 10–20 mL/kg/24 小時（Currow et al., 2015） |
| 胃減壓 | **NG tube 僅作急性期暫時減壓** | 長期放置耐受度差，可能阻塞、移位，並造成鼻軟骨侵蝕、中耳炎、吸入性肺炎等併發症（Madariaga et al., 2022，證據等級 V、D）；慢性反覆嘔吐考慮減壓胃造口（11.4） |
| 止吐 | **完全阻塞**：haloperidol 較常用；H1 antagonist（如 dimenhydrinate）可能有效；**避免 metoclopramide**（可能增加腸穿孔風險）。**部分阻塞**：metoclopramide 或 olanzapine 可能有效 | Madariaga et al., 2022；Davis et al., 2021。完全阻塞時藥物需走靜脈或皮下 |
| 抗分泌 | **octreotide**（somatostatin analogue）；hyoscine butylbromide 可能不如 octreotide，但可減輕絞痛 | MASCC 建議 octreotide（Davis et al., 2021；Madariaga et al., 2022，證據等級 I、A）。**但**兩個低偏差風險的大型安慰劑對照試驗主要指標都沒有差異（Obita et al., 2016）：Currow 試驗中 72 小時的無嘔吐天數 octreotide 1.87 天、安慰劑 1.69 天（P = 0.47），多變項分析的嘔吐次數較少（incidence rate ratio 0.40）。試驗劑量：0.3 mg/24 小時持續皮下輸注（對照 hyoscine butylbromide 60 mg/24 小時；Ripamonti et al., 2000）、0.6 mg/24 小時輸注（Currow et al., 2015） |
| 抗發炎 | **dexamethasone** 短期使用 | 4–16 mg/日；3–5 天無改善就考慮停用；試驗常用 16 mg IV 連續 5 天，並排除消化道出血史、活動性消化性潰瘍或腹膜炎（Madariaga et al., 2022，證據等級 III、B） |
| 止痛 | 依 WHO 原則使用鴉片類；完全阻塞改走 SC／IV；絞痛可加 hyoscine butylbromide | 鴉片類在 MBO 缺乏專屬證據但為常規（Madariaga et al., 2022，證據等級 V、D）；Ripamonti et al., 2008 |
| 瀉劑 | 部分阻塞可考慮滲透性瀉劑；**完全阻塞避免** | Madariaga et al., 2022，證據等級 V、D |

> [!NOTE]
> **MBO 的藥物組合與劑量依院內緩和醫療流程**
> 上表的試驗劑量只用來說明「證據用過什麼」。實際的 octreotide 途徑（分次皮下或持續皮下輸注）、haloperidol 劑量、類固醇療程與是否追加抗分泌藥，依主治醫師與院內緩和照護處方，並在 3–5 天評估療效，無效就停藥而不是無限期延長。

### 11.4 MBO：減壓、支架與手術怎麼選

| 情境 | 建議 | 依據 |
|------|------|------|
| 大腸單一位置阻塞、沒有穿孔 | **自膨式金屬支架（SEMS）為姑息性首選**，技術上可行時 | MASCC：證據等級 II、B（Madariaga et al., 2022）；ESGE：姑息性大腸阻塞以支架為首選（強建議，高品質證據；van Hooft et al., 2020） |
| 胃出口、近端小腸、近端大腸 | 支架是選項之一；近端大腸可考慮支架 | Ripamonti et al., 2008；ESGE 弱建議（van Hooft et al., 2020） |
| 多處阻塞 | 手術只用於高度篩選的病人；手術併發症風險高，優先考慮侵入性較低的方式 | MASCC（Madariaga et al., 2022，證據等級 IV、B） |
| 手術的不良預後條件 | 腹腔內癌症擴散（carcinomatosis）、體能差、大量腹水，不要常規手術 | Ripamonti et al., 2008 |
| 慢性、藥物難控制的嘔吐 | **減壓胃造口（venting gastrostomy）**，內視鏡或經皮放置 | 29 個研究：多能緩解噁心嘔吐，嚴重併發症少見，多為傷口感染或造口周圍滲漏；腹水**不是絕對禁忌**，但建議先引流腹水以降低併發症（Madariaga et al., 2022，證據等級 IV、B） |
| 診斷當下 | **盡早請外科評估**，不是等藥物失敗才找 | MASCC（Madariaga et al., 2022） |

- 手術證據品質低：Cochrane 回顧因偏差風險高，沒有進行合併分析（Cousins et al., 2016）。
- **使用 bevacizumab 的病人**：Cennamo 病例系列 28 位放置結腸支架的病人中，2 位發生結腸穿孔，兩位都同時接受 capecitabine 加 oxaliplatin 加 bevacizumab 治療（Cennamo et al., 2009）；是否同時用支架與抗血管新生藥物，需與內視鏡醫師與腫瘤科共同決定。

> [!NOTE]
> **營養支持**
> MASCC：只有在對生活品質與存活的好處大於風險、且已和病人家屬討論預期時，才開始營養介入；居家全靜脈營養僅對高度篩選的病人可能有益，預後標準之一為 ECOG < 2、沒有體液滯留與低白蛋白血症；瀕死階段不應啟動（Madariaga et al., 2022）。

### 11.5 化療期間腹痛的鑑別

化療後發燒的癌症病人如果有腹痛，鑑別診斷要同時想到：MBO、NE、*Clostridioides difficile* 感染、免疫檢查點抑制劑相關結腸炎（見 [irAE](04-irae.md)）。這幾個診斷的處置完全不同，所以腹痛病人的第一步是腹部理學檢查與影像，而不是先止痛、止瀉。

### 11.6 嗜中性球低下性小腸結腸炎（NE）

**定義與流行病學：**

- 常用的臨床定義：嗜中性球 < 500/µL、體溫 > 38.3°C、腹痛，且腹部 CT 顯示長度超過 3 cm 的腸段**腸壁厚度 > 4 mm**（Babakhanlou et al., 2023）。Gorschlüter 的系統性回顧建議以「發燒、腹痛與超音波或 CT 腸壁增厚 > 4 mm」的組合作為診斷標準（Gorschlüter et al., 2005）。
- 整合發生率約 5.3%（住院的血液惡性腫瘤、實體癌高劑量化療或再生不良性貧血病人；Gorschlüter et al., 2005）。紫杉醇類（taxane）等造成嚴重胃腸黏膜炎的藥物使發生率增加（Nesher & Rolston, 2013）。
- 盲腸幾乎都有侵犯，常延伸到迴腸；症狀常在化療結束後 2 週內出現；死亡率報告最高約 50%（Rodrigues et al., 2017）。
- CTCAE v5.0 Typhlitis：Grade 3 為有症狀（腹痛、發燒、伴腸麻痺的排便習慣改變）或腹膜徵象；Grade 4 為危及生命、需緊急手術（National Cancer Institute, 2017）。

**臨床表現：** 發燒、腹痛（常在右下腹）、腹瀉（可帶血）、噁心嘔吐、腹脹（Rodrigues et al., 2017；Nesher & Rolston, 2013）。可能出現菌血症（常為多重菌種）、出血、穿孔或膿瘍。

**診斷：**

- **腹部 CT 是首選**：腸壁增厚 > 4 mm、腸壁積氣（pneumatosis intestinalis）、腸擴張、系膜脂肪混濁（Babakhanlou et al., 2023）。
- 超音波也能看到腸壁增厚；急性白血病病人中，腸壁厚度超過 10 mm 預後較差（死亡率約 60%，較薄者約 4.2%；Cartoni et al., 2001，數字引自 Rodrigues et al., 2017）。
- **抽血液培養**，並排除 *Clostridioides difficile* 感染（Nesher & Rolston, 2013）；大腸鏡很少有適應症（血球低下加上穿孔風險；Rodrigues et al., 2017）。

> [!WARNING]
> **止瀉藥與鴉片類會蓋住警訊**
> 過度使用鴉片類與抗蠕動藥（antiperistaltic agents）會妨礙併發症的評估，應限制、最好避免（Babakhanlou et al., 2023）。FN 病人新出現的腹痛、腹瀉或腹脹，先做腹部理學檢查與 CT，再決定止痛與止瀉，不要先把症狀壓掉。

> [!TIP]
> **NE 的比喻**
> 化療把腸黏膜這道圍牆打出缺口，嗜中性球這支救災隊又都不在，腸道裡的細菌（革蘭氏陰性桿菌、厭氧菌，偶爾還有黴菌）就從缺口長驅直入腸壁，盲腸最容易受害。止瀉藥與鴉片類像「把火警鈴關掉」，火還在燒，只是你聽不到。

**治療原則：**

| 項目 | 做法 | 依據 |
|------|------|------|
| 抗生素 | 依 FN 流程，**分流後 60 分鐘內**給第一劑（先抽血液培養，但不可因此延誤）；要涵蓋革蘭氏陰性（含 *Pseudomonas*）、革蘭氏陽性與**厭氧菌**：piperacillin-tazobactam 或 carbapenem（imipenem、meropenem）單用；或 cefepime／ceftazidime 加 metronidazole。用 piperacillin-tazobactam 或 carbapenem 時不需另加 metronidazole | Rodrigues et al., 2017；Babakhanlou et al., 2023 |
| 加強覆蓋 | 病情最重者考慮加腸球菌覆蓋；*C. difficile* 尚未排除時加 metronidazole 或口服 vancomycin（靜脈 vancomycin 無法在腸腔達到治療 *C. difficile* 的濃度） | Rodrigues et al., 2017；Babakhanlou et al., 2023 |
| 抗黴菌 | 不常規一開始就加；治療 72 小時反應不佳時考慮 | Rodrigues et al., 2017 |
| 腸道休息 | NPO、靜脈輸液；有營養風險時給靜脈營養；矯正血球低下與凝血異常 | Nesher & Rolston, 2013；Rodrigues et al., 2017 |
| 止痛與止瀉 | 限制鴉片類與抗蠕動藥 | Babakhanlou et al., 2023 |
| G-CSF | 不常規使用，需個案評估 | Babakhanlou et al., 2023 |
| 手術 | 腹腔內穿孔；矯正血球與凝血後仍無法控制的出血；膿瘍或闌尾炎等其他外科病灶。穩定的病人應避免手術；可行時等嗜中性球恢復後再手術。壞死或穿孔的腸段要切除，不建議一期吻合 | Rodrigues et al., 2017；Nesher & Rolston, 2013；Babakhanlou et al., 2023 |
| 團隊 | 腫瘤科、感染科與外科共同照護，**外科早期會診** | Babakhanlou et al., 2023 |

> [!NOTE]
> **抗生素選擇與升級依院內抗生素政策**
> 上表的選擇來自綜說與回顧文章，NE 沒有前瞻性對照試驗（Gorschlüter et al., 2005）。實際用哪一種單方、何時加 carbapenem 或抗黴菌藥，依院內抗生素管理政策與 antibiogram；發燒的初始處置見第 1 節。

## 12. 惡性肋膜積水

### 12.1 結論先行

- **沒有症狀的惡性肋膜積水（malignant pleural effusion, MPE）不需要處理**；有症狀才介入（ATS/STS/STR 2018，弱建議；Feller-Kopman et al., 2018）。
- 有症狀的病人**先做大量胸腔穿刺**：同時看喘有沒有改善、肺能不能重新擴張（Feller-Kopman et al., 2018）。
- **肺可以復張**：留置肋膜導管（indwelling pleural catheter, IPC）與化學沾黏術（以 talc 為主）**二擇一**皆可，依病人偏好、預期存活與居家照護能力決定。**肺不能復張（nonexpandable／trapped lung）或沾黏失敗**：IPC 優先（Feller-Kopman et al., 2018）。
- Talc 可用胸腔鏡噴灑（poudrage）或經胸管灌入（slurry）；兩者沾黏失敗率沒有差別（TAPPS：22% 對 24%；Bhatnagar et al., 2020）。
- **IPC 感染**：用抗生素治療，**不要拔管**（Feller-Kopman et al., 2018）。
- 抽液量以**症狀**為停止依據；重大併發症 re-expansion pulmonary edema（RPE）罕見（Feller-Kopman et al., 2007）。

> [!IMPORTANT]
> **MPE 的決策樹（考點）**
> 無症狀 → 觀察；有症狀 → 治療性胸腔穿刺 → 症狀改善且肺復張 → IPC 或 talc 沾黏術；肺不復張或沾黏失敗 → IPC。MPE 帶來的是短預後，要和病人討論偏好（住院天數、居家照護、費用）而不是只比成功率。

### 12.2 辨識與診斷

- **症狀與徵象**：漸進性喘、乾咳、胸悶；患側呼吸音減弱、叩診濁音、語顫減少。
- **影像**：胸部 X 光；**胸部超音波**可引導穿刺、看分隔（loculation）；胸部 CT 看肋膜結節、肺實質與縱膈。ATS 2018 建議以超音波引導肋膜介入（弱建議）；穿刺後氣胸的整合發生率 6.0%，使用超音波顯著降低風險（OR 0.3），治療性（相對診斷性）穿刺與穿刺中出現症狀則增加氣胸風險（OR 2.6 與 26.6；Gordon et al., 2010）。
- **積水分析**：細胞計數、蛋白、LDH、葡萄糖、pH、細胞學與培養。
- **細胞學的敏感度有限**：前瞻性世代（921 位未診斷的單側積水病人）整體敏感度 46%；腺癌 79%、血液惡性腫瘤 40%、間皮瘤只有 6%（Arnold et al., 2018）。細胞學陰性但高度懷疑時，需做肋膜切片；組織診斷仍是診斷與規劃治療的黃金標準（Bibby et al., 2018）。
- **預後**：LENT 分數（肋膜液 LDH、ECOG、嗜中性球／淋巴球比值、腫瘤類型）把病人分為低、中、高風險，中位存活分別為 319、130 與 44 天（Clive et al., 2014）；可用來決定要不要選擇低住院負擔的選項（例如 IPC）。
- **全身治療不能取代引流**：沒有證據支持以腫瘤治療取代症狀性 MPE 的引流（Bibby et al., 2018）；即使全身治療有效，喘得明顯時仍應處理積水。

> [!TIP]
> **肋膜腔像肺外面的水球**
> 肋膜積水就是「肺和胸壁之間灌了水」。沾黏術（pleurodesis）像是把兩層膜黏起來，讓水沒地方存；IPC 則是「裝一個水龍頭」，水一增加就放掉。但如果肺被腫瘤或纖維包成硬殼（trapped lung），膜根本黏不到一起，裝水龍頭才是合理的選擇，所以一定要先確認肺能不能長開。

### 12.3 胸腔穿刺：技術、抽液量與肺復張評估

**專師在床邊的步驟：**

1. 確認適應症（有症狀、診斷性或治療性）、凝血功能與血小板、過敏史、病人是否同意；簽署同意書。
2. **超音波定位並標記穿刺點**，病人坐姿向前趴靠床旁桌；穿刺針沿**肋骨上緣**進入（避開肋骨下緣的血管神經束）。
3. 局部麻醉，進入肋膜腔後以引流套組或穿刺導管引流；全程詢問症狀。
4. 送檢體（見 12.2）；結束後拔除，覆蓋敷料。
5. 症狀改善與否、抽液量、顏色與穿刺過程中的反應（咳嗽、胸痛）都要記錄。

**抽多少、何時停：**

- 傳統上常限制單次抽液在 1 L 左右，目的是避免 RPE（Feller-Kopman et al., 2007）。
- 185 位大量穿刺（≥ 1 L）的病人，臨床 RPE 只有 1 位（0.5%），影像上的 RPE 4 位（2.2%）；RPE 的發生與抽液量、胸膜腔壓力與胸膜彈性都無關；作者主張大量積水可以抽乾，**只要沒有出現胸悶／胸痛，且呼氣末肋膜腔壓沒有低於 -20 cm H2O**（Feller-Kopman et al., 2007）。
- 隨機試驗顯示，常規使用壓力計（manometry）並不會降低穿刺中的胸悶，但在沒有壓力計監測的組別有 10% 發生無症狀的 ex vacuo 氣胸（有壓力計為 0%）（Lentz et al., 2019）。
- 實務上以**症狀**為停止標準：出現持續胸悶、胸痛、劇烈咳嗽就停止，並考慮肺不復張。

**如何判斷肺能不能復張：**

- 引流後胸部 X 光或超音波看肺是否貼回胸壁；
- 引流中出現胸悶或胸痛、咳嗽、ex vacuo 氣胸，是肺不復張時肋膜腔壓過度負壓的表現，也與 RPE 風險有關（Lentz et al., 2019）；
- IPC-PLUS 試驗把「肺復張不良」定義為視覺肋膜纖維化或支氣管阻塞造成的肺無法擴張與肋膜貼合（Bhatnagar et al., 2018）。

> [!WARNING]
> **大量引流中出現這些症狀要立刻停**
> 持續咳嗽、胸悶或胸痛、呼吸困難加重、血氧下降。停止引流、坐起、給氧、通知醫師並安排胸部 X 光；這可能是肺不復張、氣胸或 RPE。

### 12.4 依症狀與肺復張的處置流程

| 情境 | 建議 | 依據 |
|------|------|------|
| 無症狀 | 不做肋膜介入，追蹤；全身治療依腫瘤章節 | ATS 2018 弱建議（Feller-Kopman et al., 2018） |
| 有症狀 | 超音波引導、大量胸腔穿刺，評估喘是否改善與肺是否復張 | ATS 2018 弱建議 |
| 症狀改善且肺可復張 | **IPC 或化學沾黏術二擇一**；talc 噴灑與灌入二擇一 | ATS 2018 弱建議；TIME2、AMPLE、TAPPS |
| 肺不復張（trapped lung）或沾黏失敗 | **IPC 優先** | ATS 2018 弱建議 |
| 症狀沒有因引流而改善 | 找其他原因：淋巴管擴散、肺栓塞、肺炎、心衰竭、貧血等 | 臨床鑑別 |
| IPC 相關感染 | 抗生素治療，**保留導管** | ATS 2018 弱建議 |
| 多房性積水（loculated）、trapped lung | 證據有限，個案決定 | Bibby et al., 2018 |

### 12.5 關鍵試驗

| 試驗 | 設計與族群 | 主要結果 |
|------|-----------|---------|
| TIME2（Davies et al., 2012） | n = 106；IPC 對 talc slurry；英國 7 家醫院 | 42 天內喘的 VAS 無差異（24.7 對 24.4 mm）；6 個月時 IPC 較好（差 -14.0 mm，P = .01）；初次住院中位數 0 天對 4 天；需再次肋膜介入 talc 22% 對 IPC 6%；不良事件 IPC 21/52 對 talc 7/54 |
| AMPLE（Thomas et al., 2017） | n = 146；IPC 對 talc；澳洲、紐西蘭、新加坡、香港 | 12 個月住院天數：IPC 10 天、talc 12 天（P = .03）；與積水相關的住院天數 1 天對 4 天 |
| IPC-PLUS（Bhatnagar et al., 2018） | n = 154 隨機（139 位納入主要分析：talc 69、安慰劑 70）；IPC 引流 10 天無明顯肺纏繞者，隨機給 4 g talc slurry 或安慰劑（透過 IPC） | 第 35 天沾黏成功：talc 43%、安慰劑 23%（HR 2.20，95% CI 1.23–3.92）；未見更多阻塞或不良事件 |
| TAPPS（Bhatnagar et al., 2020） | n = 330；胸腔鏡 talc poudrage 4 g 對 床邊胸管 talc slurry 4 g | 90 天沾黏失敗：22% 對 24%（OR 0.91，P = .74） |
| ASAP（Wahidi et al., 2017） | n = 149；IPC 每日引流對隔日引流 | 自發性沾黏（autopleurodesis）47% 對 24%（P = .003）；中位時間 54 天對 90 天 |
| AMPLE-2（Muruganandan et al., 2018） | n = 87；IPC 每日引流對症狀導向引流 | 喘的 VAS 無顯著差異；60 天內自發性沾黏 37.2% 對 11.4%（P = .0049） |
| TIME1（Rahman et al., 2015） | n = 320；24F 對 12F 胸管；鴉片類對 NSAIDs | 疼痛：NSAIDs 與鴉片類無差異，但 NSAIDs 需更多救援止痛（38.1% 對 26.3%）；沾黏失敗 NSAIDs 23%、鴉片類 20%，達到非劣性；12F 疼痛較低，但失敗率 30% 對 24%，未達非劣性 |
| calibrated talc 的安全性（Janssen et al., 2007） | n = 558；4 g 大顆粒 calibrated talc poudrage | 急性呼吸窘迫症候群（ARDS）0%（單尾 95% CI 0–0.54%）；過去小顆粒 talc 曾有 1–9% 的 ARDS 報告 |

**這些試驗怎麼用：**

- 喘的改善 IPC 與 talc 相當，IPC 住院較短（Davies et al., 2012；Thomas et al., 2017）；但 TIME2 中 IPC 組的不良事件較多，talc 組則較常需要再次肋膜介入（Davies et al., 2012）。
- 想要快一點拔掉 IPC：每日引流、或在肺復張良好時經 IPC 加 talc（Wahidi et al., 2017；Muruganandan et al., 2018；Bhatnagar et al., 2018）。
- 沾黏術止痛：NSAIDs 沒有降低沾黏成功率，可以作為鴉片類的替代，但需更多救援止痛（Rahman et al., 2015）。
- 使用 calibrated 大顆粒 talc，未見 ARDS（Janssen et al., 2007）。

### 12.6 胸管與 IPC 的護理照護、居家引流衛教

**胸管（含小口徑 pigtail）與 talc 沾黏術後：**

- 維持密閉引流系統並低於胸部高度；每班記錄引流量、顏色、水封瓶有無呼吸性波動與氣泡、皮膚出口與敷料、病人的呼吸與疼痛。
- 沾黏術前後提供足夠的止痛（TIME1 可作為 NSAIDs 與鴉片類的參考；Rahman et al., 2015）；沾黏術後出現發燒，要和感染區分。
- 拔管的時機（常見為引流量下降、胸部 X 光肺已貼回胸壁）與 talc 灌入後的夾管時間，依產品說明與院內流程。

> [!NOTE]
> **胸管護理與沾黏術流程依院內規範**
> talc 的劑型與稀釋量、灌入前的局部麻醉與止痛、夾管時間、病人是否翻身、拔管標準，各院不同，專師依院內「肋膜沾黏術」流程與 order set。試驗用的 talc 為 4 g（Bhatnagar et al., 2018；Bhatnagar et al., 2020）。

**IPC 的居家引流衛教**（MSKCC 病人手冊；Jingelski et al., 2010）：

- **引流頻率與量**：起初約每隔一天引流 500–1,000 mL；症狀（例如喘）明顯可增加頻率；**單次引流不超過 1,000 mL**，除非醫師指示；每次記錄日期與引流量。
- **何時減少頻率、何時回診**：單次 < 100 mL 可改為每 3 天；**連續 3 次引流（約 9 天）每次 < 50 mL，就聯絡醫師**，拍胸部 X 光評估是否可拔管。
- **引流中有疼痛**：減慢或暫停引流；仍疼痛，引流後聯絡醫師或護理師。
- **敷料**：每週更換一次，或敷料變濕、髒、鬆脫時立刻更換；每天檢查敷料。
- **導管損壞**：捏住或夾住導管，立刻聯絡醫師。
- **立刻聯絡醫療團隊**：體溫 ≥ 38°C、引流液變色或變混濁或有異味、引流量突然改變、引流時或引流後持續疼痛。
- **沒有液體流出**：檢查引流瓶是否失去真空、管路有沒有扭折、夾子是否打開，輕輕滾動導管疏通，必要時換新的引流套組與引流瓶；仍無法引流要聯絡醫師。

**引流頻率要看目標：** 想盡快自發性沾黏、拔管，建議每日引流（ASAP：47% 對 24%；AMPLE-2：37.2% 對 11.4%）；不在意拔管、只要控制症狀，可採症狀導向引流（AMPLE-2 的喘分數沒有差異；Muruganandan et al., 2018）。引流計畫由開立醫師決定，並寫在出院衛教單上。

### 12.7 併發症

| 併發症 | 辨識 | 處置 |
|--------|------|------|
| 氣胸（含 ex vacuo） | 穿刺後胸痛、呼吸困難、血氧下降；肺不復張時引流後出現無症狀的 ex vacuo 氣胸（Lentz et al., 2019 的對照組 10%） | 停止引流、胸部 X 光；肺不復張者改以 IPC 而不是沾黏術 |
| Re-expansion pulmonary edema（RPE） | 大量引流中或後出現咳嗽、胸悶、呼吸困難、低血氧；臨床 RPE 罕見（0.5%）（Feller-Kopman et al., 2007） | 停止引流、坐起、給氧、通知醫師；嚴重者依肺水腫支持治療 |
| IPC 相關感染 | 發燒、出口紅腫流膿、引流液混濁或有異味（Jingelski et al., 2010） | 抗生素治療並保留導管（Feller-Kopman et al., 2018） |
| IPC 阻塞或引流不順 | 沒有液體、引流量突降 | 檢查真空與管路、滾動導管、換套組；仍無法引流通知醫師（Jingelski et al., 2010） |
| 沾黏術後疼痛 | 術後數小時至數天 | 規律止痛（NSAIDs 或鴉片類，Rahman et al., 2015）；持續發燒、膿性引流要排除感染 |
| 沾黏失敗／積水復發 | 症狀再出現、X 光積水復發 | 約 22–24% 在 90 天內失敗（Bhatnagar et al., 2020）；改 IPC 或再次介入 |
| talc 引起的 ARDS | 沾黏術後急性呼吸窘迫 | 使用 calibrated 大顆粒 talc 時未見（Janssen et al., 2007） |

> [!NOTE]
> **與第 8 節心包膜積液的連結**

## 13. 自我測驗

**Q1.** 一位乳癌病人化療後第 10 天在急診，口溫 38.4°C，ANC 300/µL，血壓 118/70 mmHg，意識清楚。最優先的處置是？

A. 等血液培養報告再決定抗生素　B. 抽 2 套血液培養後，60 分鐘內給 cefepime　C. 先給 G-CSF 再觀察　D. 口服 acetaminophen 退燒後返家

<details>
<summary>答案與詳解</summary>

**答案：B**。符合 FN 定義（單次口溫 ≥ 38.3°C、ANC < 500/µL），應在抽血液培養後、分流 60 分鐘內給予經驗性抗綠膿桿菌 β-lactam。是否能門診治療需在給藥後依 MASCC 等工具與臨床判斷評估。

</details>

**Q2.** 下列 MASCC 風險指數的敘述，何者正確？

A. 分數越高風險越高　B. ≥ 21 分為低風險　C. 年齡 ≥ 60 歲得 2 分　D. 住院病人得 3 分

<details>
<summary>答案與詳解</summary>

**答案：B**。MASCC 是「分數越高越安全」的低風險篩選工具，總分 26，≥ 21 分為低風險。年齡 < 60 歲得 2 分；「發燒時為門診病人」得 3 分。

</details>

**Q3.** 廣泛期小細胞肺癌、大範圍肝轉移、LDH 很高的病人即將開始化療。準備使用 rasburicase 前，最需要確認的是？

A. HLA-B\*5801　B. G6PD 是否缺乏　C. TPMT 基因型　D. DPYD 基因型

<details>
<summary>答案與詳解</summary>

**答案：B**。G6PD 缺乏者使用 rasburicase 會發生溶血與變性血紅素血症，為禁忌。HLA-B\*5801 是 allopurinol 嚴重皮膚過敏的風險基因。

</details>

**Q4.** 一位已知骨轉移的肺癌病人，新出現胸椎背痛 2 週，今天開始雙腿無力。下列處置順序何者最適當？

A. 先安排門診 MRI，下週回診　B. 立即給 dexamethasone，24 小時內全脊椎 MRI，會診放射腫瘤科與脊椎外科　C. 先開止痛藥觀察　D. 先做骨骼掃描

<details>
<summary>答案與詳解</summary>

**答案：B**。疑似惡性脊髓壓迫且已有神經學症狀或徵象（如本題的雙腿無力）時，應立即給予 dexamethasone，不需等影像；全脊椎 MRI 是首選檢查（多節段常見）。預後最重要的因子是治療時能否行走，延誤會造成不可逆的癱瘓。

</details>

**Q5.** 血鈣 12.8 mg/dL、白蛋白 2.0 g/dL，校正血鈣為？

A. 11.2 mg/dL　B. 12.8 mg/dL　C. 14.4 mg/dL　D. 16.0 mg/dL

<details>
<summary>答案與詳解</summary>

**答案：C**。校正 Ca = 12.8 ＋ 0.8 ×（4.0 − 2.0）= 12.8 ＋ 1.6 = 14.4 mg/dL。

</details>

**Q6.** 小細胞肺癌病人血鈉 112 mmol/L，出現癲癇。下列何者正確？

A. 限水即可　B. 3% NaCl 150 mL 靜脈 20 分鐘，第一個 24 小時血鈉上升不超過 10 mmol/L　C. 生理食鹽水快速輸注，目標 24 小時內矯正到 135　D. 立即口服 tolvaptan

<details>
<summary>答案與詳解</summary>

**答案：B**。嚴重症狀性低血鈉應給予 3% 高張食鹽水快速提升約 5 mmol/L 以緩解症狀；但 24 小時內上升不超過 10 mmol/L（高風險者 8 mmol/L），避免滲透性脫髓鞘。SIADH 時生理食鹽水可能無效甚至讓血鈉更低。

</details>

**Q7.** 接受 tarlatamab 的病人，體溫 38.6°C，血壓 86/50 mmHg 需要一種升壓劑，以鼻導管 3 L/min 給氧。依 ASTCT，CRS 等級為？

A. Grade 1　B. Grade 2　C. Grade 3　D. Grade 4

<details>
<summary>答案與詳解</summary>

**答案：C**。CRS 分級取低血壓與缺氧中較嚴重者：需一種升壓劑為 Grade 3（低流量給氧為 Grade 2），故整體為 Grade 3。

</details>

**Q8.** 一位懷疑淋巴瘤造成上腔靜脈症候群的病人，臉部腫脹、輕度呼吸困難，無喘鳴，意識清楚，血壓穩定。下列何者最適當？

A. 立即經驗性高劑量類固醇　B. 立即緊急放射治療　C. 先取得組織診斷　D. 立即全身化療

<details>
<summary>答案與詳解</summary>

**答案：C**。無喉頭水腫、腦水腫或血行動力不穩時，SVC 症候群通常有時間先取病理。未取病理前給類固醇或放射治療，可能讓淋巴瘤病理判讀失準。

</details>

**Q9.** 一位卵巢癌病人第一次輸注 paclitaxel，開始後約 5 分鐘出現胸悶、呼吸困難、全身蕁麻疹，血壓 78/40 mmHg。最適當的第一步處置是？

A. 停止輸注、保留靜脈通路，立即 epinephrine 0.5 mg 肌肉注射（大腿前外側）　B. 把輸注速率降為一半，觀察 30 分鐘　C. 先靜脈注射 diphenhydramine，無效再給 epinephrine　D. 靜脈快速推注 epinephrine 1 mg

<details>
<summary>答案與詳解</summary>

**答案：A**。皮膚症狀加上呼吸與低血壓，符合 WAO 2020 的 anaphylaxis 標準。第一步是停止輸注並保留靜脈通路，接著盡早給 epinephrine IM：成人 0.01 mg/kg、單次最多 0.5 mg，打在大腿前外側，未改善每 5–15 分鐘可重複。抗組織胺只是輔助，不能延誤 epinephrine；靜脈快速推注可能引發致命心律不整，不是初始治療。

</details>

**Q10.** 關於成人 anaphylaxis 的 epinephrine 用法，下列何者正確？

A. 0.1 mg 靜脈推注，每 1 分鐘重複　B. 0.3 mg 皮下注射於上臂，僅給一次　C. 0.01 mg/kg（單次最多 0.5 mg）肌肉注射於大腿前外側，未改善每 5–15 分鐘可重複　D. 先給 hydrocortisone，30 分鐘後視情況再給 epinephrine

<details>
<summary>答案與詳解</summary>

**答案：C**。WAO 2020 建議由醫療人員給予 0.01 mg/kg（最多 0.5 mg）肌肉注射，部位是股外側肌（大腿前外側），症狀未改善每 5–15 分鐘重複。靜脈途徑不建議用於初始治療，難治者才由有經驗的醫師以幫浦持續輸注；類固醇的急性期益處不明，不能取代或先於 epinephrine。

</details>

**Q11.** 一位卵巢癌病人接受第 8 個週期的 carboplatin，輸注過半時手掌發癢、全身蕁麻疹並出現喘鳴。下列何者最正確？

A. 這是第一次暴露才會出現的反應，下次可直接加快輸注　B. 只要下次加 dexamethasone 前置用藥就可以安全再給　C. 這種反應與紫杉醇反應無法區分，不需要轉介　D. 這是已多次暴露後的過敏反應；若仍需使用鉑類，應轉介過敏免疫科評估（例如減敏），不要自行再挑戰

<details>
<summary>答案與詳解</summary>

**答案：D**。Carboplatin 的過敏反應多出現在已經使用很多個週期之後（Markman 系列中首次反應的鉑類療程數中位數為第 8 次），且臨床表現與紫杉醇反應不同（手腳掌發癢、全身蕁麻疹較常見）。多數病人首次反應後不再挑戰（Banerji et al., 2014）；Markman 系列 3 例再挑戰只有 1 例成功。需要繼續鉑類時，由過敏免疫科與腫瘤科評估快速減敏。

</details>

**Q12.** 輸注反應在症狀改善後再度出現，依 CTCAE v5.0（Infusion related reaction）屬於哪一級？

A. Grade 1　B. Grade 3　C. Grade 2　D. Grade 4

<details>
<summary>答案與詳解</summary>

**答案：B**。CTCAE v5.0 的 Grade 3 定義為反應延長（對症狀治療或短暫中斷輸注反應不佳）、症狀改善後再度出現，或因後遺症需住院。Grade 2 是需處置或中斷輸注，但對症狀治療反應迅速；Grade 4 為危及生命、需緊急處置。

</details>

**Q13.** 62 歲卵巢癌病人，腹膜擴散、ECOG 3、大量腹水，CT 顯示多處小腸阻塞、無穿孔，嘔吐難以控制。下列何者最適當？

A. NPO、止吐（完全阻塞可用 haloperidol）、考慮 octreotide 與短期 dexamethasone，與外科及緩和醫療討論，必要時考慮減壓胃造口　B. 立即剖腹探查做腸繞道　C. 給 metoclopramide 促進腸蠕動並加瀉劑　D. 放置大腸支架

<details>
<summary>答案與詳解</summary>

**答案：A**。腹膜擴散、體能差與大量腹水是手術的不良預後條件；多處阻塞只在高度篩選的病人考慮手術。完全阻塞應避免 metoclopramide 與瀉劑，藥物走靜脈或皮下。大腸支架適用於單一位置的大腸阻塞。藥物難控制的嘔吐可考慮減壓胃造口（腹水不是絕對禁忌，建議先引流腹水）。

</details>

**Q14.** 關於惡性腸阻塞的藥物與支持治療，下列何者正確？

A. 完全阻塞時 metoclopramide 是首選止吐藥　B. dexamethasone 需連續使用數週才有效　C. 靜脈輸液能預防口乾口渴並延長存活　D. 部分阻塞可考慮滲透性瀉劑，完全阻塞要避免

<details>
<summary>答案與詳解</summary>

**答案：D**。MASCC 建議：滲透性瀉劑可考慮用於部分阻塞，完全阻塞避免。Metoclopramide 在完全阻塞時可能增加腸穿孔風險，應避免。Dexamethasone 為短期使用（4–16 mg/日，3–5 天無改善就考慮停用）。靜脈輸液不能預防或改善口乾口渴，也不增加存活，過量還可能造成水腫。

</details>

**Q15.** 乳癌病人 docetaxel 後第 9 天，ANC 200/µL，體溫 38.9°C，右下腹痛、水瀉，CT 見盲腸壁增厚 8 mm，無游離氣體。最適當的處置是？

A. 給 loperamide 與 morphine 緩解症狀後返家　B. 口服 ciprofloxacin 門診追蹤　C. 抽血液培養後 60 分鐘內給含厭氧菌覆蓋的廣效抗生素（如 piperacillin-tazobactam），NPO，早期會診外科　D. 立即剖腹探查做右半結腸切除

<details>
<summary>答案與詳解</summary>

**答案：C**。嗜中性球低下加發燒、腹痛與 CT 腸壁增厚 > 4 mm，符合嗜中性球低下性小腸結腸炎（NE）。處置是 FN 流程加含厭氧菌覆蓋的廣效抗生素（piperacillin-tazobactam 或 carbapenem 單用，或 cefepime／ceftazidime 加 metronidazole）、腸道休息並早期會診外科。止瀉藥與鴉片類會妨礙併發症的評估，應避免；沒有穿孔、無法控制的出血或膿瘍時不需手術。

</details>

**Q16.** 下列何者是嗜中性球低下性小腸結腸炎（NE）的手術適應症？

A. 單純腸壁增厚大於 4 mm　B. 腸穿孔，或矯正血球與凝血功能後仍無法控制的出血，或膿瘍等其他外科病灶　C. ANC 低於 100/µL　D. 發燒超過 3 天

<details>
<summary>答案與詳解</summary>

**答案：B**。NE 多數以藥物治療，穩定的病人應避免手術。手術適應症是腹腔內穿孔、矯正血球與凝血異常後仍無法控制的出血，以及膿瘍、闌尾炎等其他外科病灶；可行時等嗜中性球恢復後再手術。腸壁增厚、嚴重嗜中性球低下與持續發燒本身不是手術適應症。

</details>

**Q17.** 肺腺癌病人右側大量肋膜積水，穿刺引流 1.4 L 後喘明顯改善，胸部 X 光顯示肺已貼回胸壁。下列何者符合 ATS/STS/STR 2018 指引？

A. 一律先做胸腔鏡 talc poudrage　B. 因症狀已改善，不需要任何進一步處置　C. 只有留置肋膜導管（IPC）是合理選擇　D. IPC 或化學沾黏術（talc）二擇一均為合理選擇，依病人偏好、預期存活與居家照護能力決定

<details>
<summary>答案與詳解</summary>

**答案：D**。有症狀的 MPE、症狀因引流改善且肺可復張時，指引（弱建議）認為 IPC 與化學沾黏術皆可。TIME2 與 AMPLE 顯示 IPC 的住院較短，喘的改善相當；talc 噴灑或灌入沾黏失敗率相近（TAPPS 22% 對 24%）。積水若會復發且仍有症狀，只觀察不處理並不合適。

</details>

**Q18.** 病人抽液 1.2 L 後出現胸悶與咳嗽，胸部 X 光出現氣胸，肺沒有貼回胸壁。下一步最適當的是？

A. 懷疑肺不復張（non-expandable lung），停止抽液；日後若需持續處理積水，IPC 優先於化學沾黏術　B. 繼續把積水抽乾以便做沾黏術　C. 立即經穿刺針灌入 talc　D. 診斷為 re-expansion pulmonary edema，給利尿劑並繼續抽液

<details>
<summary>答案與詳解</summary>

**答案：A**。引流中出現胸悶、咳嗽與 ex vacuo 氣胸，是肺不復張時肋膜腔壓力過度負壓的表現，應停止抽液。肺不復張或沾黏失敗者，指引建議 IPC 優於沾黏術（沾黏需要兩層肋膜能貼在一起）。RPE 罕見，處置是停止引流、給氧與支持治療，不是繼續抽液。

</details>

**Q19.** 一位使用 IPC 居家引流的病人發燒 38.5°C，導管出口紅腫、引流液混濁。依 ATS/STS/STR 2018 指引，最適當的處理是？

<details>
<summary>答案與詳解</summary>

**答案：C**。指引（弱建議）建議 IPC 相關感染以抗生素治療，並不要拔除導管。病人與照顧者要學會辨識感染徵象（發燒、出口紅腫流膿、引流液變混濁或有異味）並立即聯絡醫療團隊。
